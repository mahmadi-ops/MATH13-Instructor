    1.

    Sketch the domain of \(f(x,y) = \sqrt{y - 3x}\text{.}\)
    🔗
    Solution.
    The square root is defined exactly when its argument is non-negative, so the domain is
    \begin{equation*} \{(x,y) : y - 3x \ge 0\} = \{(x,y) : y \ge 3x\}, \end{equation*}
    the closed half-plane on and above the line \(y = 3x\text{.}\) See Figure 5.10.48.

    2.

    In Figure 5.10.49 are level curves of \(g(x,y) = 2\) and \(g(x,y) = 3\) for some function \(g(x,y)\text{.}\) What’s wrong?
    🔗
    Solution.
    Two level curves belonging to different values can never intersect. At the point \(P\) where the drawn curves cross, the first curve says \(g(P) = 2\) while the second says \(g(P) = 3\text{.}\) Since \(g\) is a function, it assigns exactly one output to the point \(P\text{,}\) so \(2 = 3\) — which is impossible. Hence no function \(g\) can have the level curves shown.

    3.

    Let \(g\) be a function of 3 variables defined by
    \begin{equation*} g(x,y,z) = \sqrt{4x^2 + y^2 + 9z^2}. \end{equation*}
    Find the equation for the level surface of \(g\) through the point \(\left(2, \sqrt{11}, 1\right)\) and sketch this level surface. Label any points where the surface crosses a coordinate axis AND label the value of \(g\) on the surface.
    🔗
    Solution.
    Evaluating \(g\) at the given point,
    \begin{equation*} g\left(2, \sqrt{11}, 1\right) = \sqrt{4(4) + 11 + 9(1)} = \sqrt{36} = 6, \end{equation*}
    so the level surface is \(g(x,y,z) = 6\text{,}\) i.e.
    \begin{align*} \sqrt{4x^2 + y^2 + 9z^2} = 6 \amp \;\Rightarrow\; 4x^2 + y^2 + 9z^2 = 36\\ \amp \;\Rightarrow\; \frac{x^2}{9} + \frac{y^2}{36} + \frac{z^2}{4} = 1. \end{align*}
    This is an ellipsoid with semi-axes \(3\text{,}\) \(6\text{,}\) and \(2\text{.}\) It crosses the axes at \((\pm 3, 0, 0)\text{,}\) \((0, \pm 6, 0)\text{,}\) and \((0, 0, \pm 2)\text{.}\) See Figure 5.10.50.
    🔗

    4.

    Sketch the level surface \(f(x,y,z) = z^2 - x^2 - y^2\) for \(f(x,y,z) = 4\text{.}\)
    🔗
    Solution.
    The level surface is \(z^2 - x^2 - y^2 = 4\text{,}\) i.e.
    \begin{equation*} \frac{z^2}{4} - \frac{x^2}{4} - \frac{y^2}{4} = 1. \end{equation*}
    Rewriting as \(z^2 = 4 + x^2 + y^2\) shows that \(z^2 \ge 4\text{,}\) so \(z \ge 2\) or \(z \le -2\text{:}\) no part of the surface lies between the two horizontal planes \(z = \pm 2\text{.}\) The traces are
    • \(z = c\) with \(|c| \gt 2\text{:}\) \(x^2 + y^2 = c^2 - 4\text{,}\) circles;
      🔗
      🔗
    • \(x = c\text{:}\) \(z^2 - y^2 = 4 + c^2\text{,}\) hyperbolas;
      🔗
      🔗
    • \(y = c\text{:}\) \(z^2 - x^2 = 4 + c^2\text{,}\) hyperbolas.
      🔗
      🔗
    Hence the level surface is a hyperboloid of two sheets, symmetric about the \(z\)-axis, with vertices \((0,0,\pm 2)\text{.}\) See Figure 5.10.51.

    5. True or False.

      If \(\lim\limits_{(x,y)\to(a,b)} f(x,y)\) exists, the function \(f(x,y)\) must be defined or continuous at \((a,b)\text{.}\)
      🔗
      Justify your answer fully: give a proof if the statement is true, or a counterexample if it is false.
      🔗

    • True.

    • We can for example define \(f(x,y)\) to be zero when \((x,y) \ne (0,0)\) and to be \(1\) when \((x,y) = (0,0)\text{.}\) If we then pick \((a,b) = (0,0)\text{,}\) the limit of \(f(x,y)\) for \((x,y) \to (a,b)\) exists but it is not equal to \(f(a,b)\text{.}\) We could also leave \(f(x,y)\) undefined at the origin to give another counterexample.

    • False.

    • We can for example define \(f(x,y)\) to be zero when \((x,y) \ne (0,0)\) and to be \(1\) when \((x,y) = (0,0)\text{.}\) If we then pick \((a,b) = (0,0)\text{,}\) the limit of \(f(x,y)\) for \((x,y) \to (a,b)\) exists but it is not equal to \(f(a,b)\text{.}\) We could also leave \(f(x,y)\) undefined at the origin to give another counterexample.

      🔗
      Justify your answer fully: give a proof if the statement is true, or a counterexample if it is false.

      Along every straight line passing through the origin this will be constant \(0\) near the origin, but the limit approaching via the parabola \(y = x^2\) is \(1\text{.}\) See Figure 5.10.52.

    7.

    Discuss continuity of the following functions:
    1. \(\displaystyle \dfrac{2x^4 y}{x^8 + y^2}\)
      🔗
      🔗
    2. \(\displaystyle \dfrac{x^2\cos^2 x}{x^2 + (y-1)^2}\)
      🔗
      🔗
    🔗
    Solution.
    1. This is obviously continuous whenever the denominator is nonzero, i.e. everywhere except at the origin. But at the origin it is not continuous (or rather we can’t extend the function to the origin in a way which makes it continuous): if we approach the origin via any of the coordinate axes we get a limit of \(0\text{,}\) but if we approach it via the path \(y = x^4\) we get a limit
      \begin{equation*} \lim_{x\to 0} \frac{2x^4 x^4}{x^8 + x^8} = 1. \end{equation*}
      Hence the limit \(\lim\limits_{(x,y)\to(0,0)} f(x,y)\) does not exist.
      🔗
      🔗
    2. This is continuous when the denominator is nonzero, so everywhere except at \((0,1)\text{.}\) At \((0,1)\) it can’t be defined in a way which makes the function continuous: approaching \((0,1)\) via the \(y\)-axis, we get the limit
      \begin{equation*} \lim_{y\to 1} \frac{0\cdot\cos^2(0)}{(y-1)^2} = 0. \end{equation*}
      On the other hand, if we approach \((0,1)\) on the line \(y = 1\) we get the limit
      \begin{equation*} \lim_{x\to 0} \frac{x^2\cos^2 x}{x^2} = \cos^2(0) = 1. \end{equation*}
      🔗
      🔗

    8.

    Evaluate each of the following limits or show that it does not exist.
    1. \(\displaystyle \displaystyle\lim_{(x,y)\to(0,0)} \frac{xy^5}{x^8 + y^{10}}\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle\lim_{(x,y)\to(1,1)} \frac{x^8 - y^8}{x^4 - y^4}\)
      🔗
      🔗
    🔗
    Solution.
    1. Along the path \(x = y^5\text{:}\)
      \begin{equation*} \lim_{(x,y)\to(0,0)} \frac{xy^5}{x^8 + y^{10}} = \lim_{y\to 0} \frac{y^{10}}{y^{40} + y^{10}} = \lim_{y\to 0} \frac{1}{y^{30} + 1} = 1. \end{equation*}
      Along the path \(x = 0\text{:}\)
      \begin{equation*} \lim_{(x,y)\to(0,0)} \frac{xy^5}{x^8 + y^{10}} = \lim_{y\to 0} \frac{0}{0 + y^{10}} = 0. \end{equation*}
      Since \(1 \ne 0\text{,}\) the limit does not exist.
      🔗
      🔗
    2. We factor the numerator as a difference of squares:
      \begin{align*} \lim_{(x,y)\to(1,1)} \frac{x^8 - y^8}{x^4 - y^4} \amp = \lim_{(x,y)\to(1,1)} \frac{\left(x^4 - y^4\right)\left(x^4 + y^4\right)}{x^4 - y^4}\\ \amp = \lim_{(x,y)\to(1,1)} x^4 + y^4 = 2. \end{align*}
      🔗
      🔗
    🔗
    🔗

    9.

    Find the limit, if it exists, or show that it does not exist:
    \begin{equation*} \lim_{(x,y)\to(1,1)} \frac{x^2 + y^2 - 2}{|x-1| + |y-1|}. \end{equation*}
    🔗
    Solution.
    Along the path \(x = 1\text{,}\) \(y \to 1^{+}\) (so that \(|y - 1| = y - 1\)):
    \begin{equation*} \lim_{y\to 1^{+}} \frac{y^2 - 1}{y - 1} = \lim_{y\to 1^{+}} \frac{(y-1)(y+1)}{y-1} = \lim_{y\to 1^{+}} (y + 1) = 2. \end{equation*}
    Along the path \(x = 1\text{,}\) \(y \to 1^{-}\) (so that \(|y - 1| = -(y - 1)\)):
    \begin{equation*} \lim_{y\to 1^{-}} \frac{y^2 - 1}{-(y - 1)} = \lim_{y\to 1^{-}} -(y + 1) = -2. \end{equation*}
    Since the limits computed along the two paths are not equal, the limit does not exist.
    🔗
    🔗

    10.

    Find the following limit, if it exists, or show that it does not exist:
    \begin{equation*} \lim_{(x,y)\to(0,0)} \frac{y^4}{x^4 + 3y^4}. \end{equation*}
    🔗
    Solution.
    Along the path \(x = 0\text{:}\)
    \begin{equation*} \lim_{(x,y)\to(0,0)} \frac{y^4}{x^4 + 3y^4} = \lim_{y\to 0} \frac{y^4}{3y^4} = \frac13. \end{equation*}
    Along the path \(y = x\text{:}\)
    \begin{equation*} \lim_{(x,y)\to(0,0)} \frac{y^4}{x^4 + 3y^4} = \lim_{x\to 0} \frac{x^4}{x^4 + 3x^4} = \frac14. \end{equation*}
    Since \(\frac13 \ne \frac14\text{,}\) the limit does not exist.

    11. Higher order computation.

    Prove that \(c(x,t) = \dfrac{1}{\sqrt{Dt}}\,e^{-\frac{x^2}{4Dt}}\) is a solution of the diffusion equation
    \begin{equation*} \frac{\partial c}{\partial t} = D\,\frac{\partial^2 c}{\partial x^2}. \end{equation*}
    🔗
    Solution.
    We compute the needed derivatives:
    \begin{align*} \frac{\partial c}{\partial t} \amp = -\frac{1}{2\sqrt{D}\,t^{3/2}}\,e^{-x^2/4Dt} + \frac{1}{\sqrt{Dt}}\,\frac{x^2}{4Dt^2}\,e^{-x^2/4Dt}\\ \frac{\partial c}{\partial x} \amp = -\frac{x}{2Dt}\,\frac{1}{\sqrt{Dt}}\,e^{-x^2/4Dt}\\ \frac{\partial^2 c}{\partial x^2} \amp = -\frac{1}{2Dt\sqrt{Dt}}\,e^{-x^2/4Dt} + \frac{x^2}{4D^2t^2}\,\frac{1}{\sqrt{Dt}}\,e^{-x^2/4Dt} \end{align*}
    🔗
    We see that the right hand side of the third equation is \(\dfrac{1}{D}\) times the right hand side of the first, i.e. multiplying \(\dfrac{\partial^2 c}{\partial x^2}\) by \(D\) gives exactly \(\dfrac{\partial c}{\partial t}\text{,}\) showing that \(c\) satisfies the diffusion equation.
    🔗

    12.

    Let \(f(x,y,z) = xy + 3y^2z^3 + \ln(xz)\text{.}\) Compute \(\dfrac{\partial^2 f}{\partial x^2}\) and \(\dfrac{\partial^2 f}{\partial y \partial z}\text{.}\)
    🔗
    Solution.
    Note first that \(\ln(xz) = \ln x + \ln z\text{,}\) which makes the differentiation easier. Treating the other variables as constants,
    \begin{equation*} \frac{\partial f}{\partial x} = y + \frac1x \;\Rightarrow\; \frac{\partial^2 f}{\partial x^2} = -\frac{1}{x^2}. \end{equation*}
    For the mixed partial, differentiate first with respect to \(z\) and then with respect to \(y\text{:}\)
    \begin{equation*} \frac{\partial f}{\partial z} = 9y^2z^2 + \frac1z \;\Rightarrow\; \frac{\partial^2 f}{\partial y \partial z} = \frac{\partial}{\partial y}\left(9y^2z^2 + \frac1z\right) = 18yz^2. \end{equation*}
    🔗
    🔗

    13.

    A metal plate occupies the square \(0 \le x \le 5\text{,}\) \(0 \le y \le 5\text{,}\) and is heated so that the temperature at the point \((x,y)\) is \(T(x,y)\text{,}\) measured in degrees Fahrenheit. Distances are measured in feet. The table below records some measured values of \(T\text{.}\)
    🔗
    1. Approximate \(T_x(1,1)\) and interpret your answer, with units, in the context of the problem.
      🔗
      🔗
    2. Approximate \(T_{xy}(1,1)\text{,}\) and give its units.
      🔗
      🔗
    3. An ant walks across the plate along the path
      \begin{equation*} x = 1 - \frac{\ln(2t-3)}{8}, \qquad y = \frac{2^t}{4}, \qquad 1.5 \lt t \lt 4 . \end{equation*}
      Approximate the rate at which the temperature the ant feels is changing at the moment it is at the point \((x,y) = (1,1)\text{,}\) and give the units.
      🔗
      🔗
    🔗
    Solution.
    (a) A partial derivative is a limit of difference quotients, so with the data we have we approximate it by a difference quotient. Holding \(y=1\) fixed and stepping forward in \(x\) from \(x=1\) to \(x=1.5\text{,}\)
    \begin{equation*} T_x(1,1) \approx \frac{T(1.5,1) - T(1,1)}{1.5-1} = \frac{74-70}{0.5} = 8 . \end{equation*}
    The units are degrees Fahrenheit per foot. The interpretation: at the point \((1,1)\text{,}\) if the ant moves in the positive \(x\)-direction while its \(y\)-coordinate stays fixed, the temperature increases at a rate of about \(8\,{}^{\circ}\text{F}\) per foot.
    🔗
    (b) By definition \(T_{xy} = (T_x)_y\text{,}\) so we compute \(T_x\) at two different values of \(y\) and then take a difference quotient in \(y\text{.}\) We already have \(T_x(1,1) \approx 8\text{,}\) and in the same way
    \begin{equation*} T_x(1,1.5) \approx \frac{T(1.5,1.5) - T(1,1.5)}{0.5} = \frac{68-65}{0.5} = 6 . \end{equation*}
    Therefore
    \begin{equation*} T_{xy}(1,1) \approx \frac{T_x(1,1.5) - T_x(1,1)}{1.5-1} = \frac{6-8}{0.5} = -4 . \end{equation*}
    The units are degrees Fahrenheit per foot per foot, i.e. \({}^{\circ}\text{F}/\text{ft}^2\text{.}\) This says that as we move in the \(y\)-direction, the rate at which the temperature rises in the \(x\)-direction is itself decreasing.
    🔗
    (c) First we find the value of \(t\) at which the ant is at \((1,1)\text{.}\) We need
    \begin{align*} 1 - \frac{\ln(2t-3)}{8} = 1 \amp \quad\Longrightarrow\quad \ln(2t-3) = 0\\ \amp \quad\Longrightarrow\quad 2t-3 = 1 \quad\Longrightarrow\quad t = 2 , \end{align*}
    and indeed \(y = 2^2/4 = 1\) at \(t=2\text{,}\) as required. Note that \(t=2\) lies in the given interval \(1.5 \lt t \lt 4\text{.}\)
    🔗
    Next we differentiate the path:
    \begin{align*} \frac{dx}{dt} \amp = -\frac{1}{8}\cdot\frac{2}{2t-3} = -\frac{1}{4(2t-3)}, \amp \frac{dx}{dt}\bigg|_{t=2} \amp = -\frac{1}{4} ,\\ \frac{dy}{dt} \amp = \frac{2^t \ln 2}{4}, \amp \frac{dy}{dt}\bigg|_{t=2} \amp = \frac{4\ln 2}{4} = \ln 2 . \end{align*}
    🔗
    We also need \(T_y(1,1)\text{,}\) which we approximate from the table just as before, stepping forward in \(y\text{:}\)
    \begin{equation*} T_y(1,1) \approx \frac{T(1,1.5) - T(1,1)}{0.5} = \frac{65-70}{0.5} = -10 . \end{equation*}
    🔗
    Now the chain rule gives
    \begin{align*} \frac{dT}{dt} \amp = T_x\,\frac{dx}{dt} + T_y\,\frac{dy}{dt}\\ \amp \approx (8)\left(-\frac14\right) + (-10)(\ln 2)\\ \amp = -2 - 10\ln 2 \approx -8.93 . \end{align*}
    The units are degrees Fahrenheit per unit of \(t\) (per minute, if \(t\) is measured in minutes). So the ant is cooling off at about \(8.9\,{}^{\circ}\text{F}\) per unit of time. This makes sense: the ant is moving slightly in the \(-x\) direction, which cools it a little, and it is moving in the \(+y\) direction, which cools it a lot. Figure 5.10.54 shows the situation.
