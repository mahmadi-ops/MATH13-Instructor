    1. True or False.

      If \(f(x,y)\) has two local maxima, then it must have a local minimum too.
      🔗
      Justify your answer fully: give a proof if the statement is true, or a counterexample if it is false.
      🔗

    • True.

    • This is true for single-variable functions but no longer holds in two dimensions. For example, the function \(f(x,y) = -x^4 + x^2 - \frac12 y^2\text{,}\) shown in Figure 5.15.74, has two local maxima at \(\left(\pm\frac{1}{\sqrt2}, 0\right)\) with a saddle point at the origin lying between them, and no local minimum.

    • False.

    • This is true for single-variable functions but no longer holds in two dimensions. For example, the function \(f(x,y) = -x^4 + x^2 - \frac12 y^2\text{,}\) shown in Figure 5.15.74, has two local maxima at \(\left(\pm\frac{1}{\sqrt2}, 0\right)\) with a saddle point at the origin lying between them, and no local minimum.

    2.

    Let \(f(x,y) = x^2 - y^2 - 2x + 4y + 6\text{.}\) Find all the critical points and classify them as local maxima, local minima, and saddle points.
    🔗
    Solution.
    The first and second partial derivatives are
    \begin{align*} f_x \amp = 2x - 2, \amp f_{xx} \amp = 2, \amp f_{xy} \amp = f_{yx} = 0,\\ f_y \amp = -2y + 4, \amp f_{yy} \amp = -2. \end{align*}
    Setting \(f_x = 0\) gives \(x = 1\) and \(f_y = 0\) gives \(y = 2\text{,}\) so the only critical point is \((1,2)\text{.}\) The Hessian is
    \begin{equation*} H(x,y) = \begin{vmatrix} f_{xx} \amp f_{xy} \\ f_{xy} \amp f_{yy} \end{vmatrix} = \begin{vmatrix} 2 \amp 0 \\ 0 \amp -2 \end{vmatrix} = -4 \lt 0, \end{equation*}
    so \((1,2)\) is a saddle point since the Hessian is negative.
    🔗
    🔗
    🔗

    3.

    Find the absolute maximum and absolute minimum of \(f(x,y) = 2 + xy - 2x - \frac14 y^2\) in the closed triangular region with vertices given by \((0,0)\text{,}\) \((1,0)\text{,}\) and \((0,2)\text{.}\)
    🔗
    Solution.
    Critical points:
    \begin{equation*} f_x = y - 2 = 0 \;\Rightarrow\; y = 2, \qquad f_y = x - \frac{y}{2} = 0 \;\Rightarrow\; x = 1, \end{equation*}
    so the only critical point is \((1,2)\text{.}\) Note that this point is NOT in the closed region \(R\text{,}\) so we only need to check the boundary.
    🔗
    The boundary: we check the three sides of the triangle.
    • \(L_1\text{:}\) \(x = 0\text{,}\) \(0 \le y \le 2\text{.}\) Here \(f(0,y) = 2 - \frac{y^2}{4}\text{,}\) with maximum \(2\) at \((0,0)\) and minimum \(1\) at \((0,2)\text{.}\)
      🔗
      🔗
    • \(L_2\text{:}\) \(y = 0\text{,}\) \(0 \le x \le 1\text{.}\) Here \(f(x,0) = 2 - 2x\text{,}\) with maximum \(2\) at \((0,0)\) and minimum \(0\) at \((1,0)\text{.}\)
      🔗
      🔗
    • \(L_3\text{:}\) \(y = -2x + 2\text{,}\) \(0 \le x \le 1\text{.}\) Here
      \begin{equation*} g(x) = f(x, -2x+2) = 2 - 2x^2 - (x-1)^2 = 1 - 3x^2 + 2x, \end{equation*}
      and \(g'(x) = -6x + 2 = 0\) gives \(x = \frac13\text{,}\) \(y = \frac43\text{,}\) with \(f\left(\frac13, \frac43\right) = 2 + \frac49 - \frac23 - \frac49 = \frac43\text{.}\) The endpoints of \(L_3\) give the previously found values \(1\) and \(0\text{.}\)
      🔗
      🔗
    🔗
    Comparing all the values, the absolute maximum of \(f\) is \(2\text{,}\) attained at \((0,0)\text{,}\) and the absolute minimum is \(0\text{,}\) attained at \((1,0)\text{.}\) See Figure 5.15.75.
    🔗

    4.

    The porosity of the soil beneath an elliptical section of a field, \(x^2 + 4y^2 \le 25\text{,}\) is given by
    \begin{equation*} f(x,y) = 2x^2 - 9x + 2y^2 + 20. \end{equation*}
    Find the \((x,y)\) location(s) in this section of the field where water will drain the fastest and slowest, i.e. the locations where porosity is an absolute maximum or absolute minimum.
    🔗
    Solution.
    The region is closed and bounded and \(f\) is a polynomial, hence continuous, so by the Extreme Value Theorem absolute extrema exist. We check the interior and the boundary.
    🔗
    Interior critical points:
    \begin{equation*} f_x = 4x - 9 = 0 \;\Rightarrow\; x = \frac94, \qquad f_y = 4y = 0 \;\Rightarrow\; y = 0. \end{equation*}
    The point \(\left(\frac94, 0\right)\) satisfies \(\left(\frac94\right)^2 = \frac{81}{16} \approx 5.06 \lt 25\text{,}\) so it lies inside the region, and
    \begin{align*} f\left(\frac94, 0\right) \amp = 2\left(\frac{81}{16}\right) - 9\left(\frac94\right) + 20\\ \amp = \frac{81}{8} - \frac{81}{4} + 20 = -\frac{81}{8} + 20 = \frac{79}{8} = 9.875. \end{align*}
    🔗
    The boundary: on \(x^2 + 4y^2 = 25\) we have \(y^2 = \dfrac{25 - x^2}{4}\) with \(-5 \le x \le 5\text{,}\) so
    \begin{equation*} f = 2x^2 - 9x + 2\cdot\frac{25-x^2}{4} + 20 = \frac32 x^2 - 9x + \frac{65}{2}, \end{equation*}
    a function of the single variable \(x\text{.}\) Setting its derivative to zero,
    \begin{equation*} 3x - 9 = 0 \;\Rightarrow\; x = 3 \;\Rightarrow\; y^2 = \frac{25-9}{4} = 4 \;\Rightarrow\; y = \pm 2, \end{equation*}
    with \(f(3, \pm 2) = \frac{27}{2} - 27 + \frac{65}{2} = 19\text{.}\) At the endpoints of the interval,
    \begin{equation*} f(5, 0) = \frac{75}{2} - 45 + \frac{65}{2} = 25, \qquad f(-5, 0) = \frac{75}{2} + 45 + \frac{65}{2} = 115. \end{equation*}
    🔗
    Comparing all the values \(\left\{\frac{79}{8}, 19, 25, 115\right\}\text{,}\) the porosity is an absolute maximum of \(115\) at \((-5, 0)\) — where water drains the fastest — and an absolute minimum of \(\frac{79}{8}\) at \(\left(\frac94, 0\right)\) — where water drains the slowest. See Figure 5.15.76.
    🔗

    5. A product on a circle.

    Find the maximum and minimum values of the function \(f(x,y) = 4xy\) subject to the constraint \(x^2 + y^2 = 8\text{.}\)
    🔗
    Solution.
    Write the constraint as
    \begin{equation*} g(x,y) = x^2 + y^2 - 8 = 0, \end{equation*}
    so that \(g_x = 2x\) and \(g_y = 2y\text{,}\) while \(f_x = 4y\) and \(f_y = 4x\text{.}\) The Lagrange condition \(\nabla f = \lambda\,\nabla g\) gives
    \begin{equation*} 4y = 2\lambda x, \qquad 4x = 2\lambda y. \end{equation*}
    🔗
    Solving each equation for \(\lambda\text{,}\)
    \begin{equation*} \lambda = \frac{2y}{x} = \frac{2x}{y} \qquad\Longrightarrow\qquad x^2 = y^2. \end{equation*}
    Substituting into the constraint \(x^2 + y^2 - 8 = 0\) gives \(2x^2 = 8\text{,}\) so
    \begin{equation*} x = \pm 2, \qquad y = \pm 2. \end{equation*}
    Hence there are four extrema: \((2,2)\text{,}\) \((2,-2)\text{,}\) \((-2,2)\text{,}\) \((-2,-2)\text{.}\)
    🔗
    Evaluating \(f\) at the four candidates:
    🔗
    \((x,y)\) \(f(x,y)\)
    \((2,2)\) \(16\)
    \((-2,-2)\) \(16\)
    \((2,-2)\) \(-16\)
    \((-2,2)\) \(-16\)
    The maximum value is \(16\text{,}\) attained at \((2,2)\) and \((-2,-2)\text{;}\) the minimum value is \(-16\text{,}\) attained at \((2,-2)\) and \((-2,2)\text{.}\)
    🔗
    Geometric interpretation. A rectangle with corners \((\pm x, \pm y)\) inscribed in the circle \(x^2+y^2=8\) has area exactly \(4xy = f(x,y)\text{.}\) As the corner \((x,y)\) moves along the circle, we obtain rectangles of different areas.
    🔗
    The values of \((x,y)\) that maximize \(f\) are exactly the values that maximize the area of the inscribed rectangle.

    6.

    Consider \(f(x,y) = xy\) and \(x^2 - y = 12\text{.}\) We assume \(y \le 0\text{.}\)
    1. Why do we need \(y \le 0\) here?
      🔗
      🔗
    2. Find the extreme values of \(f\) subject to the above constraints.
      🔗
      🔗
    🔗
    Solution.
    1. Else a minimum and maximum would not exist, since we could just pick \(y\) very large and \(x = \pm\sqrt{y + 12}\) would also have a very large magnitude, resulting in a very large or very negative value of \(f(x,y)\text{.}\)
      🔗
      🔗
    2. The constraint describes the portion of the parabola \(y = x^2 - 12\) in the third and fourth quadrant. This shape is closed and bounded so we are guaranteed the existence of global maxima and minima. The two boundary points, which occur at \(y = 0\text{,}\) need to be handled separately; this part is not very hard, since we immediately see that \(f\) has value \(0\) on them.
      🔗
      Now we proceed to find the critical points of \(f\) on the parabola \(g(x,y) = x^2 - y - 12 = 0\text{.}\) The system of equations we need to solve is obtained from \(\nabla f(x,y) = \langle y, x\rangle\) and \(\nabla g(x,y) = \langle 2x, -1\rangle\text{.}\) It is
      \begin{align*} y \amp = 2\lambda x\\ x \amp = -\lambda\\ x^2 - y \amp = 12 \end{align*}
      Combining the first two equations we see that \(y = -2x^2\text{,}\) and using the third, \(3x^2 = 12\text{,}\) so \(x = \pm 2\) and \(y = -8\text{.}\) Computing the value of \(f\) at these points, we see that the global maximum of \(f\) is at \((-2, -8)\) with a value of \(16\text{,}\) while the global minimum with value \(-16\) is at \((2, -8)\text{.}\) See Figure 5.15.79.

    7.

    Find the point(s) on the surface \(xyz = 1\) closest to the origin.
    🔗
    Solution.
    The distance of a point from the origin is \(\sqrt{x^2 + y^2 + z^2}\text{,}\) so it suffices to minimize \(f(x,y,z) = x^2 + y^2 + z^2\) with the constraint \(g(x,y,z) = xyz - 1 = 0\text{.}\) The Lagrange system \(\nabla f = \lambda \nabla g\) is
    \begin{equation*} \langle 2x, 2y, 2z\rangle = \langle \lambda yz, \lambda xz, \lambda xy\rangle. \end{equation*}
    Multiplying the first equation by \(x\) and using \(xyz = 1\text{,}\)
    \begin{equation*} 2x = \lambda yz \;\Rightarrow\; 2x^2 = \lambda xyz \;\overset{xyz=1}{\Rightarrow}\; 2x^2 = \lambda \;\Rightarrow\; x^2 = \frac{\lambda}{2}, \end{equation*}
    and similarly \(y^2 = \dfrac{\lambda}{2}\) and \(z^2 = \dfrac{\lambda}{2}\text{,}\) hence \(x^2 = y^2 = z^2\text{.}\)
    🔗
    Substituting into the constraint,
    \begin{equation*} x^2 y^2 z^2 = 1 \;\Rightarrow\; x^6 = 1 \;\Rightarrow\; x^2 = 1. \end{equation*}
    Since \(xyz = 1\text{,}\) we know that \(x\text{,}\) \(y\text{,}\) and \(z\) are either all positive or two are negative and the third one is positive. Hence, the closest points are
    \begin{equation*} (1,1,1), \quad (1,-1,-1), \quad (-1,1,-1), \quad (-1,-1,1). \end{equation*}
    🔗
    🔗
    🔗

    8.

    Find the point \(P(x,y,z)\) closest to the origin on the plane \(2x + y - z - 5 = 0\text{.}\)
    🔗
    Solution.
    The distance from the origin is \(\sqrt{x^2+y^2+z^2}\text{,}\) so it suffices to minimize the function \(f(x,y,z) = x^2 + y^2 + z^2\) subject to the constraint \(g(x,y,z) = 2x + y - z - 5 = 0\text{.}\) We compute
    \begin{equation*} \nabla f = \langle 2x, 2y, 2z\rangle, \qquad \nabla g = \langle 2, 1, -1\rangle. \end{equation*}
    🔗
    The Lagrange system \(\nabla f = \lambda \nabla g\) is
    \begin{align*} 2x \amp = 2\lambda \amp \;\Rightarrow\; x \amp = \lambda,\\ 2y \amp = \lambda \amp \;\Rightarrow\; y \amp = \frac{\lambda}{2},\\ 2z \amp = -\lambda \amp \;\Rightarrow\; z \amp = -\frac{\lambda}{2}. \end{align*}
    Substituting into the equation of the plane,
    \begin{equation*} 2\lambda + \frac{\lambda}{2} + \frac{\lambda}{2} - 5 = 0 \;\Rightarrow\; 3\lambda = 5 \;\Rightarrow\; \lambda = \frac53. \end{equation*}
    Hence the closest point is
    \begin{equation*} P\left(\frac53,\; \frac56,\; -\frac56\right). \end{equation*}
    🔗
    (Only one critical point arises, and the distance certainly has a minimum on the plane but no maximum, so this point must be the minimizer.)

    9.

    Find the minimum value of \(x + y^2 + z^3\) along the part of the plane \(x + y + z = 2\) in the first octant (\(x, y, z \ge 0\)). The solution found by Lagrange multipliers gives the minimum. Use common sense for the maximum value.
    🔗
    Solution.
    Let \(f(x,y,z) = x + y^2 + z^3\) and \(g(x,y,z) = x + y + z - 2 = 0\text{.}\) Then
    \begin{equation*} \nabla f = \left\langle 1, 2y, 3z^2\right\rangle, \qquad \nabla g = \langle 1, 1, 1\rangle, \end{equation*}
    and \(\nabla f = \lambda \nabla g\) gives
    \begin{equation*} 1 = \lambda, \qquad 2y = \lambda, \qquad 3z^2 = \lambda. \end{equation*}
    Hence \(\lambda = 1\text{,}\) \(y = \frac12\text{,}\) and \(z = \frac{1}{\sqrt3}\) (taking the positive root, since \(z \ge 0\)). From the constraint, \(x = 2 - \frac12 - \frac{1}{\sqrt3} = \frac32 - \frac{1}{\sqrt3}\text{,}\) which is positive, so the point is in the first octant.
    🔗
    The minimum value is therefore
    \begin{align*} f \amp = \left(\frac32 - \frac{1}{\sqrt3}\right) + \frac14 + \frac{1}{3\sqrt3}\\ \amp = \frac74 - \frac{1}{\sqrt3} + \frac{1}{3\sqrt3} = \frac74 - \frac{3}{3\sqrt3} + \frac{1}{3\sqrt3}\\ \amp = \frac74 - \frac{2}{3\sqrt3} = \frac74 - \frac23\sqrt{\frac13}. \end{align*}
    🔗
    For the maximum, note that the region is a triangle with vertices \((2,0,0)\text{,}\) \((0,2,0)\text{,}\) and \((0,0,2)\text{.}\) Since the largest power dominates, the largest value should occur at the vertex where all the “weight” is on \(z\text{.}\) Checking the three vertices,
    \begin{equation*} f(2,0,0) = 2, \qquad f(0,2,0) = 4, \qquad f(0,0,2) = 8, \end{equation*}
    so the maximum value is \(8\text{,}\) attained at \((0,0,2)\text{.}\)

    10. Classify the Critical Points.

      The function \(f(x,y) = x^3 - 3x + y^3 - 3y\) has four critical points. Drag each one into the correct category.
      🔗
    • \((1,1)\)
    • Local minimum
    • \((-1,-1)\)
    • Local maximum
    • \((1,-1)\)
    • \((-1,1)\)
    • Saddle point
    Solution.
    From \(f_x = 3x^2 - 3 = 0\) and \(f_y = 3y^2 - 3 = 0\) we get \(x = \pm 1\) and \(y = \pm 1\text{,}\) giving four critical points. Since \(f_{xx} = 6x\text{,}\) \(f_{yy} = 6y\) and \(f_{xy} = 0\text{,}\)
    \begin{equation*} D = f_{xx}f_{yy} - f_{xy}^2 = 36xy . \end{equation*}
    So \(D = 36 \gt 0\) at \((1,1)\) and \((-1,-1)\text{,}\) while \(D = -36 \lt 0\) at \((1,-1)\) and \((-1,1)\) — both saddles. Among the two with \(D \gt 0\text{,}\) the sign of \(f_{xx}\) decides: \(f_{xx}(1,1) = 6 \gt 0\) gives a local minimum, and \(f_{xx}(-1,-1) = -6 \lt 0\) gives a local maximum.
