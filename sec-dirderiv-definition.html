    Subsection 4.5.1 The Definition of the Directional Derivative

    Definition 4.5.1. Directional Derivative.

    The derivative of \(f\) at \(P_0(x_0,y_0)\) in the direction of the unit vector \(\hat{u} = u_1\hat{\imath} + u_2\hat{\jmath}\) is the number
    \begin{equation} \left(\frac{df}{ds}\right)_{\hat{u},\,P_0} = \lim_{s\to 0}\frac{f(x_0 + su_1,\; y_0 + su_2) - f(x_0,y_0)}{s},\tag{4.5.1} \end{equation}
    provided the limit exists. It can alternatively be denoted by \(\left(D_{\hat{u}} f\right)_{P_0}\text{.}\)
    🔗
    🔗
    The geometry behind this definition is best seen in a picture. Starting at the point \(P_0(x_0,y_0)\text{,}\) we move a distance \(s\) in the direction of the unit vector \(\hat{u}\) to reach the point \(P(x_0 + su_1,\, y_0 + su_2)\text{,}\) and we compare the values of the surface \(z = f(x,y)\) above the two points. As \(s \to 0\text{,}\) the point \(P\) slides back along \(\hat{u}\) toward \(P_0\text{.}\) The four figures that follow show this from complementary angles: Figure 4.5.2 lets you explore the construction in space, Figure 4.5.3 records the displacement in the \(xy\)-plane, Figure 4.5.4 animates the secant line rotating onto the tangent line, and Figure 4.5.5 reports the difference quotient itself as \(s\) shrinks, so that the limit can be watched rather than only read.
    🔗
    Before developing any shortcuts, we evaluate a directional derivative straight from Definition 4.5.1. Working through the limit once makes the definition concrete, and it gives us a value to check against later: Example 4.5.13 recovers the same number in a couple of lines, once the gradient is available.
    🔗

    Example 4.5.6. Example I.

    Consider the function \(f(x,y) = 1 + x^2 + y^2\text{,}\) the point \(P_0(1,1)\text{,}\) and the unit vector \(\hat{u} = \dfrac{1}{\sqrt 2}\hat{\imath} + \dfrac{1}{\sqrt 2}\hat{\jmath}\text{.}\) Use the definition of directional derivative to compute \(\left(D_{\hat{u}} f\right)_{P_0}\text{.}\)
    🔗
    Solution.
    We substitute \(x_0 = y_0 = 1\) and \(u_1 = u_2 = \dfrac{1}{\sqrt 2}\) in the definition:
    \begin{align*} \left(\frac{df}{ds}\right)_{\hat{u},P_0} \amp= \lim_{s\to 0}\frac{f(x_0 + su_1,\, y_0 + su_2) - f(x_0,y_0)}{s}\\ \amp= \lim_{s\to 0} \frac{f\!\left(1 + \tfrac{s}{\sqrt 2},\, 1 + \tfrac{s}{\sqrt 2}\right) - f(1,1)}{s}\\ \amp= \lim_{s\to 0} \frac{1 + \left(1 + \tfrac{s}{\sqrt 2}\right)^2 + \left(1 + \tfrac{s}{\sqrt 2}\right)^2 - 3}{s}\\ \amp= \lim_{s\to 0}\frac{\tfrac{4s}{\sqrt 2} + s^2}{s} = \lim_{s\to 0}\left(\tfrac{4}{\sqrt 2} + s\right)\\ \amp= 2\sqrt 2. \end{align*}
    🔗
    The computation has a useful geometric picture, illustrated in the interactive 3D figure below. Along the ray through \(P_0(1,1)\) in the direction \(\hat{u}\text{,}\) the values of \(f\) are the single-variable function
    \begin{align} g(s) \amp= f\!\left(1 + \tfrac{s}{\sqrt 2},\, 1 + \tfrac{s}{\sqrt 2}\right)\notag\\ \amp= 3 + 2\sqrt 2\, s + s^2,\tag{4.5.2} \end{align}
    and the difference quotient in the limit above is the slope of the secant line of \(g\) through \(s = 0\) and \(s\text{.}\) As \(s \to 0\) the secant lines approach the tangent line at \(s = 0\text{,}\) whose slope is \(g'(0) = 2\sqrt 2 = \left(D_{\hat{u}} f\right)_{P_0}\text{.}\)
    🔗
    🔗
    🔗

    Activity 4.5.1.1. The Partial Derivatives Are Directional Derivatives.

    Definition 4.5.1 measures the rate of change of \(f\) in an arbitrary direction \(\hat{u}\text{.}\) Two directions are already familiar from \(f_x\) and \(f_y\text{.}\) In this activity you will check that the definition reproduces exactly those two derivatives when \(\hat{u}\) points along a coordinate axis. Use only (4.5.1); nothing beyond the definition is needed.
    🔗

    (a)

    Take \(\hat{u} = \hat{\imath}\text{,}\) so that \(u_1 = 1\) and \(u_2 = 0\text{.}\) Substitute these into (4.5.1) and simplify. Which single-variable limit is left, and what is its value?
    🔗
    Hint.
    Ask yourself which of the two inputs of \(f\) actually changes as \(s\) varies.
    🔗
    🔗
    Answer.
    Substituting \(u_1 = 1\) and \(u_2 = 0\) leaves the second slot of \(f\) fixed at \(y_0\text{:}\)
    \begin{align*} \left(\frac{df}{ds}\right)_{\hat{\imath},\,P_0} \amp= \lim_{s\to 0}\frac{f(x_0 + s\cdot 1,\; y_0 + s\cdot 0) - f(x_0,y_0)}{s}\\ \amp= \lim_{s\to 0}\frac{f(x_0 + s,\; y_0) - f(x_0,y_0)}{s} = f_x(x_0,y_0). \end{align*}
    🔗
    Only the first variable moves, so this is precisely the limit that defines the partial derivative with respect to \(x\text{.}\) That is, \(\left(D_{\hat{\imath}} f\right)_{P_0} = f_x(x_0,y_0)\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Repeat the computation with \(\hat{u} = \hat{\jmath}\text{,}\) and state the conclusion.
    🔗
    Answer.
    Now \(u_1 = 0\) and \(u_2 = 1\text{,}\) so the first slot is held at \(x_0\text{:}\)
    \begin{align*} \left(\frac{df}{ds}\right)_{\hat{\jmath},\,P_0} \amp= \lim_{s\to 0}\frac{f(x_0,\; y_0 + s) - f(x_0,y_0)}{s} = f_y(x_0,y_0), \end{align*}
    so \(\left(D_{\hat{\jmath}} f\right)_{P_0} = f_y(x_0,y_0)\text{.}\) The partial derivatives are the directional derivatives in the two coordinate directions, and \(D_{\hat{u}} f\) is the common generalization of both.
    🔗
    🔗
    🔗

    (c)

    Test this on the function of Example 4.5.6. With \(f(x,y) = 1 + x^2 + y^2\) and \(P_0(1,1)\text{,}\) compute \(\left(D_{\hat{\imath}} f\right)_{P_0}\) straight from the definition, then compute \(f_x(1,1)\) in the usual way and compare.
    🔗
    Answer.
    From the definition,
    \begin{align*} \left(D_{\hat{\imath}} f\right)_{P_0} \amp= \lim_{s\to 0}\frac{f(1+s,\,1) - f(1,1)}{s} = \lim_{s\to 0}\frac{\left[1 + (1+s)^2 + 1\right] - 3}{s}\\ \amp= \lim_{s\to 0}\frac{2s + s^2}{s} = \lim_{s\to 0}\,(2 + s)\\ \amp= 2 . \end{align*}
    🔗
    Differentiating instead, \(f_x = 2x\text{,}\) so \(f_x(1,1) = 2\text{.}\) The two agree. By symmetry \(\left(D_{\hat{\jmath}} f\right)_{P_0} = f_y(1,1) = 2\) as well. Note that both are smaller than the value \(2\sqrt 2\) found in Example 4.5.6: the function climbs faster along the diagonal than along either axis.
    🔗
    🔗
    🔗

    (d)

    Finally, take \(\hat{u} = -\hat{\imath}\text{.}\) Show that \(\left(D_{-\hat{\imath}} f\right)_{P_0} = -f_x(x_0,y_0)\text{,}\) and say in a sentence why this is what you should expect.
    🔗
    Answer.
    Here \(u_1 = -1\) and \(u_2 = 0\text{,}\) so
    \begin{align*} \left(D_{-\hat{\imath}} f\right)_{P_0} \amp= \lim_{s\to 0}\frac{f(x_0 - s,\; y_0) - f(x_0,y_0)}{s} . \end{align*}
    🔗
    Putting \(h = -s\) turns this into \(-\lim_{h\to 0}\dfrac{f(x_0+h,\,y_0) - f(x_0,y_0)}{h} = -f_x(x_0,y_0)\text{.}\) Walking the opposite way along the same line makes \(f\) change at the same rate with the opposite sign, so reversing \(\hat{u}\) reverses the sign of \(D_{\hat{u}} f\text{.}\)
    🔗
    🔗
    🔗
    Every partial derivative is a directional derivative, so nothing already known about \(f_x\) and \(f_y\) is lost. What the definition adds is the freedom to point \(\hat{u}\) anywhere. Keep in mind that this depends on \(\hat{u}\) being a unit vector: the parameter \(s\) measures actual distance travelled in the \(xy\)-plane only when \(\|\hat{u}\| = 1\text{.}\)
