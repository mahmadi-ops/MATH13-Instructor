    Worksheet 5.2 Assignment 2
    

    These problems work with sequences, finite sums and geometric series, ask whether a series converges and what it sums to, and then use the Maclaurin series of the standard functions to recognise a sum. If you would like to review the material first, see Infinite Series and Taylor and Maclaurin Series.
    🔗

    1.

    The terms of a geometric series \(a + ar + ar^2 + \cdots + ar^{n-1} + \cdots\) satisfy
    \begin{equation*} a_5 + a_7 = 1500 \quad\text{and}\quad a_{11} + a_{13} = 187500, \end{equation*}
    where \(a_n = ar^{n-1}\) denotes the \(n\)th term. Find \(a_1 + a_2 + a_3\text{.}\)
    🔗
    Solution.
    Using \(a_n = ar^{n-1}\text{,}\)
    \begin{align*} a_5 + a_7 \amp = ar^4 + ar^6 = ar^4(1 + r^2) = 1500,\\ a_{11} + a_{13} \amp = ar^{10} + ar^{12} = ar^{10}(1 + r^2) = 187500. \end{align*}
    Dividing the two equations,
    \begin{equation*} \frac{a_{11} + a_{13}}{a_5 + a_7} = \frac{ar^{10}(1+r^2)}{ar^{4}(1+r^2)} = \frac{187500}{1500} \;\Rightarrow\; r^6 = 125 = 5^3 \;\Rightarrow\; r^2 = 5. \end{equation*}
    🔗
    Substituting back,
    \begin{equation*} ar^4(1 + r^2) = 1500 \;\Rightarrow\; a(25)(1+5) = 1500 \;\Rightarrow\; a = \frac{1500}{150} = 10. \end{equation*}
    Since \(r^2 = 5\text{,}\) we have \(r = \pm\sqrt5\text{,}\) and therefore
    \begin{align*} a_1 + a_2 + a_3 \amp = a + ar + ar^2 = a(1 + r + r^2)\\ \amp = 10\left(1 \pm \sqrt5 + 5\right) = 10\left(6 \pm \sqrt5\right). \end{align*}
    🔗
    🔗

    2.

    What is the sum of all multiples of 7 or 11 less than 1000?
    🔗
    Solution.
    Note that we need to subtract the multiples of \(77\text{,}\) since they have been added twice:
    \begin{align*} \amp \underbrace{(7 + 14 + 21 + \cdots + 77 + \cdots + 994)}_{\text{multiples of } 7}\\ \amp \quad + \underbrace{(11 + 22 + \cdots + 77 + \cdots + 990)}_{\text{multiples of } 11}\\ \amp \quad - \underbrace{(77 + 154 + \cdots + 924)}_{\text{multiples of } 77}\\ \amp = 7(1 + 2 + 3 + \cdots + 142) + 11(1 + 2 + 3 + \cdots + 90)\\ \amp \quad - 77(1 + 2 + \cdots + 12) \end{align*}
    🔗
    Using \(\displaystyle\sum_{i=1}^{n} i = \frac{n(n+1)}{2}\text{:}\)
    \begin{align*} \amp = 7\,\frac{(142)(143)}{2} + 11\,\frac{(90)(91)}{2} - 77\,\frac{(12)(13)}{2}\\ \amp = 7(71)(143) + 11(45)(91) - 77(6)(13)\\ \amp = (7)(71)(13)(11) + (11)(13)(7)(45) - (7)(11)(6)(13)\\ \amp = (7)(11)(13)(71 + 45 - 6) = (7)(11)(13)(110) = 110110, \end{align*}
    where we used \(143 = (13)(11)\) and \(91 = (13)(7)\text{.}\)

    3.

    What can we conclude by applying the \(n\)th term test in the following series?
    1. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \frac{(5n+3)^{2n}}{(7n^2+2)^{n}}\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \frac{2\ln(n)}{3n}\)
      🔗
      🔗
    🔗
    Solution.
    1. \begin{align*} \lim_{n\to\infty} \frac{(5n+3)^{2n}}{(7n^2+2)^{n}} \amp = \lim_{n\to\infty} \left(\frac{(5n+3)^2}{7n^2+2}\right)^{n}\\ \amp = \lim_{n\to\infty} \left(\frac{25n^2 + 30n + 9}{7n^2+2}\right)^{n}\\ \amp = \lim_{n\to\infty} \left(\frac{25}{7}\right)^{n} = \infty \;\Rightarrow\; \text{the series diverges.} \end{align*}
      🔗
      🔗
    2. \begin{align*} \lim_{n\to\infty} \frac{2\ln(n)}{3n} \amp \;\overset{\text{H}}{=}\; \frac23 \lim_{n\to\infty} \frac{1/n}{1} = 0\\ \amp \;\Rightarrow\; \text{the } n\text{th Term Test is inconclusive.} \end{align*}
      🔗
      🔗
    🔗

    4.

    Evaluate the following sums or show that they diverge.
    1. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \frac{1}{n(n+1)(n+2)}\)
      🔗
      🔗
    2. \(\displaystyle \displaystyle\sum_{n=0}^{\infty} e^{-2n}\)
      🔗
      🔗
    3. \(\displaystyle \displaystyle\sum_{n=0}^{\infty} e^{2n}\)
      🔗
      🔗
    4. \(\displaystyle \displaystyle\sum_{n=1}^{\infty} \left(1 + \frac4n\right)^{n}\)
      🔗
      🔗
    5. \(\displaystyle \displaystyle\sum_{n=2}^{\infty} \frac{2}{3^n}\)
      🔗
      🔗
    🔗
    Solution.
    1. We use partial fractions:
      \begin{align*} \frac{1}{n(n+1)(n+2)} \amp = \frac{A}{n} + \frac{B}{n+1} + \frac{C}{n+2}\\ \amp = \frac{A(n+1)(n+2) + Bn(n+2) + Cn(n+1)}{n(n+1)(n+2)}. \end{align*}
      Setting \(n = 0\) gives \(2A = 1\text{,}\) so \(A = \frac12\text{;}\) setting \(n = -1\) gives \(-B = 1\text{,}\) so \(B = -1\text{;}\) and setting \(n = -2\) gives \(2C = 1\text{,}\) so \(C = \frac12\text{.}\) Hence
      \begin{align*} \amp \sum_{n=1}^{\infty} \frac{1}{n(n+1)(n+2)}\\ \amp = \sum_{n=1}^{\infty} \frac12\left(\frac1n - \frac{2}{n+1} + \frac{1}{n+2}\right)\\ \amp = \frac12 \sum_{n=1}^{\infty} \left(\frac1n - \frac{1}{n+1}\right) - \frac12 \sum_{n=1}^{\infty} \left(\frac{1}{n+1} - \frac{1}{n+2}\right)\\ \amp = \frac12 \sum_{n=1}^{\infty} \left(\frac1n - \frac{1}{n+1}\right) - \frac12 \sum_{n=2}^{\infty} \left(\frac1n - \frac{1}{n+1}\right)\\ \amp = \frac12\left(1 - \frac12\right)\\ \amp \qquad + \underbrace{\frac12 \sum_{n=2}^{\infty} \left(\frac1n - \frac{1}{n+1}\right) - \frac12 \sum_{n=2}^{\infty} \left(\frac1n - \frac{1}{n+1}\right)}_{\text{zero}}\\ \amp = \frac14. \end{align*}
      🔗
      🔗
    2. This is a geometric series with \(a = 1\) and \(r = \frac{1}{e^2}\text{:}\)
      \begin{align*} \sum_{n=0}^{\infty} e^{-2n} \amp = \sum_{n=0}^{\infty} \left(\frac{1}{e^2}\right)^{n} = \sum_{n=1}^{\infty} \left(\frac{1}{e^2}\right)^{n-1}\\ \amp = \frac{1}{1 - \frac{1}{e^2}} = \frac{e^2}{e^2 - 1}. \end{align*}
      🔗
      🔗
    3. \(\lim\limits_{n\to\infty} a_n = \lim\limits_{n\to\infty} e^{2n} = \infty\text{,}\) so by the \(n\)th Term Test the series diverges.
      🔗
      🔗
    4. Let \(L = \lim\limits_{n\to\infty} \left(1 + \frac4n\right)^{n}\text{.}\) Then
      \begin{align*} \ln L \amp = \lim_{n\to\infty} n \ln\!\left(1 + \frac4n\right) = \lim_{n\to\infty} \frac{\ln\!\left(1 + \frac4n\right)}{\frac1n}\\ \amp \;\overset{\text{H}}{=}\; \lim_{n\to\infty} \frac{\dfrac{-4/n^2}{1 + 4/n}}{-\dfrac{1}{n^2}} = \lim_{n\to\infty} \frac{4}{1 + \frac4n} = 4. \end{align*}
      Hence \(L = e^4 \ne 0\text{,}\) so by the \(n\)th Term Test the series diverges.
      🔗
      🔗
    5. \begin{align*} \sum_{n=2}^{\infty} \frac{2}{3^n} \amp = \sum_{n=2}^{\infty} 2\left(\frac13\right)^{n}\\ \amp = \frac{2}{1-\frac13} - \left(2 + \frac23\right) = 3 - \frac83 = \frac13, \end{align*}
      where the terms for \(n = 0\) and \(n = 1\) need to be subtracted.
      🔗
      🔗

    5.

    Answer questions A and B below for the following infinite series:
    \begin{equation*} \sum_{k=1}^{\infty} \left(\frac{6}{k^2} - \frac{6}{(k+1)^2}\right). \end{equation*}
    1. Does the \(n\)th-term test apply? Remember to fully justify your answer.
      🔗
      🔗
    2. Evaluate the series or show that it diverges.
      🔗
      🔗
    🔗
    Solution.
    1. We compute the limit of the terms:
      \begin{align*} \lim_{n\to\infty} a_n \amp = \lim_{n\to\infty} \frac{6}{n^2} - \frac{6}{(n+1)^2} = \lim_{n\to\infty} \frac{6(n+1)^2 - 6n^2}{n^2(n+1)^2}\\ \amp = \lim_{n\to\infty} \frac{12n + 6}{n^2(n+1)^2} = \lim_{n\to\infty} \frac{12n}{n^4} = 0. \end{align*}
      Hence the \(n\)th-term test does not apply: since the limit of the terms is \(0\text{,}\) the test is inconclusive.
      🔗
      🔗
    2. The series telescopes. The partial sum is
      \begin{align*} s_n \amp = \left(\frac{6}{1^2} - \frac{6}{2^2}\right) + \left(\frac{6}{2^2} - \frac{6}{3^2}\right) + \cdots\\ \amp \quad + \left(\frac{6}{(n-1)^2} - \frac{6}{n^2}\right) + \left(\frac{6}{n^2} - \frac{6}{(n+1)^2}\right)\\ \amp = 6 - \frac{6}{(n+1)^2}, \end{align*}
      and therefore
      \begin{equation*} \sum_{k=1}^{\infty} \left(\frac{6}{k^2} - \frac{6}{(k+1)^2}\right) = \lim_{n\to\infty} s_n = \lim_{n\to\infty} 6 - \frac{6}{(n+1)^2} = 6 - 0 = 6. \end{equation*}
      🔗
      🔗
    🔗

    6.

    Express \(8.81818181818\ldots\) as a rational number, i.e. in the form \(\dfrac{p}{q}\text{,}\) where \(p\) and \(q\) are positive integers with no common factors.
    🔗
    Solution.
    We write the repeating decimal as a geometric series:
    \begin{equation*} 8.81818181818\ldots = 8 + \frac{81}{100} + \frac{81}{10000} + \cdots = 8 + 81 \sum_{n=1}^{\infty} \left(\frac{1}{100}\right)^{n}. \end{equation*}
    Using the geometric series with \(a = \frac{1}{100}\) and \(r = \frac{1}{100}\text{,}\)
    \begin{equation*} 8 + 81\left(\frac{\frac{1}{100}}{1 - \frac{1}{100}}\right) = 8 + \frac{81}{99} = 8 + \frac{9}{11} = \frac{97}{11}. \end{equation*}
    Hence \(p = 97\) and \(q = 11\text{.}\)

    7.

    Find the sum of the convergent series \(\displaystyle\sum_{n=0}^{\infty} \frac{(-25)^n}{(2n)!}\text{.}\)
    🔗
    Solution.
    Recall \(\cos x = \displaystyle\sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!}\text{.}\) With \(x = 5\text{,}\)
    \begin{align*} \cos(5) \amp = \sum_{n=0}^{\infty} \frac{(-1)^n 5^{2n}}{(2n)!} = \sum_{n=0}^{\infty} \frac{(-1)^n 25^{n}}{(2n)!}\\ \amp = \sum_{n=0}^{\infty} \frac{(-25)^{n}}{(2n)!}, \end{align*}
    so the sum is \(\cos(5)\text{.}\)

    8.

    Find the sum of the series \(\displaystyle\sum_{n=0}^{\infty} \frac{1}{n!}\text{.}\)
    🔗
    Solution.
    The Maclaurin series of the exponential function is
    \begin{equation*} e^{x} = \sum_{n=0}^{\infty} \frac{x^n}{n!}, \qquad \text{valid for all } x \in \R. \end{equation*}
    Setting \(x = 1\) gives
    \begin{equation*} \sum_{n=0}^{\infty} \frac{1}{n!} = e^{1} = e. \end{equation*}
    🔗
    🔗
    🔗

    9.

    Find the sum of the series
    \begin{equation*} 5 + 5^2 + \frac{5^3}{2!} + \frac{5^4}{3!} + \cdots + \frac{5^{n+1}}{n!} + \cdots \end{equation*}
    🔗
    Solution.
    The general term is \(\dfrac{5^{n+1}}{n!}\) starting at \(n = 0\text{.}\) Let us check the first few: at \(n=0\) we get \(5^1/0! = 5\text{;}\) at \(n=1\) we get \(5^2/1! = 5^2\text{;}\) at \(n = 2\) we get \(5^3/2!\text{.}\) These match, so the series is
    \begin{equation*} \sum_{n=0}^{\infty} \frac{5^{n+1}}{n!} . \end{equation*}
    🔗
    Now pull out one factor of \(5\text{,}\) which does not depend on \(n\text{:}\)
    \begin{equation*} \sum_{n=0}^{\infty} \frac{5^{n+1}}{n!} = \sum_{n=0}^{\infty} \frac{5\cdot 5^{n}}{n!} = 5\sum_{n=0}^{\infty} \frac{5^{n}}{n!} . \end{equation*}
    🔗
    The remaining series is the Maclaurin series \(\displaystyle e^{x} = \sum_{n=0}^{\infty}\frac{x^n}{n!}\) evaluated at \(x = 5\text{,}\) which converges for every \(x\text{.}\) Therefore
    \begin{equation*} 5 + 5^2 + \frac{5^3}{2!} + \cdots = 5e^5 . \end{equation*}
