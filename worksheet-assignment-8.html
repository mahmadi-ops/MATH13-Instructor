    These problems apply the chain rule to functions of several variables: differentiating a composition both by the chain rule and by substitution, deciding a True/False statement about a rate along a curve, proving Euler’s relation for homogeneous functions, and working through a dependency tree with two intermediate levels. They then use the gradient to compute directional derivatives, find directions of fastest change, and read a contour map. If you would like to review the material first, see The Chain Rule and Directional Derivatives and Gradient Vectors.

    1.

    Compute the partial derivatives of \(f\) with respect to \(x, y\) for
    \begin{equation*} f(s,t) = s^2 - t^2, \qquad s = \frac{x+y}{2}, \qquad t = \frac{x-y}{2}, \end{equation*}
    using both the chain rule and by plugging in \(s\) and \(t\text{.}\)
    🔗
    Solution.
    Using the chain rule:
    \begin{align*} \frac{\partial f}{\partial x} \amp = \frac{\partial f}{\partial s}\frac{\partial s}{\partial x} + \frac{\partial f}{\partial t}\frac{\partial t}{\partial x}\\ \amp = 2s\cdot\frac12 - 2t\cdot\frac12 = s - t = y\\ \frac{\partial f}{\partial y} \amp = \frac{\partial f}{\partial s}\frac{\partial s}{\partial y} + \frac{\partial f}{\partial t}\frac{\partial t}{\partial y}\\ \amp = 2s\cdot\frac12 + 2t\cdot\frac12 = s + t = x \end{align*}
    🔗
    Plugging in, we see
    \begin{equation*} f(s(x,y), t(x,y)) = \frac14\left((x+y)^2 - (x-y)^2\right) = xy, \end{equation*}
    and easily obtain the same partial derivatives.

    2. True or False.

      Consider \(f(x,y) = \left(\cos x + (1+x)\tan y\right)e^{x^2-1+y}\text{.}\) Then \(\dfrac{d}{dt}f(t^2, t^3) = 0\) at \(t = 0\text{.}\)
      🔗
      Justify your answer fully: give a proof if the statement is true, or a counterexample if it is false.
      🔗

    • True.

    • Writing \(x(t) = t^2\) and \(y(t) = t^3\text{,}\) we see that
      \begin{equation*} \frac{dx}{dt} = 2t = 0 \quad\text{and}\quad \frac{dy}{dt} = 3t^2 = 0 \quad\text{at } t = 0. \end{equation*}
      Now we see from the chain rule that
      \begin{equation*} \frac{d}{dt}f(x(t), y(t)) = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} = 0 \quad\text{at } t = 0. \end{equation*}

    • False.

    • Writing \(x(t) = t^2\) and \(y(t) = t^3\text{,}\) we see that
      \begin{equation*} \frac{dx}{dt} = 2t = 0 \quad\text{and}\quad \frac{dy}{dt} = 3t^2 = 0 \quad\text{at } t = 0. \end{equation*}
      Now we see from the chain rule that
      \begin{equation*} \frac{d}{dt}f(x(t), y(t)) = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} = 0 \quad\text{at } t = 0. \end{equation*}

    3. Homogeneous functions.

    A function \(f\) is called homogeneous of degree \(n\) if it satisfies the equation
    \begin{equation} f(tx, ty) = t^n f(x,y)\tag{5.11.1} \end{equation}
    for all \(t\text{,}\) where \(n\) is a positive integer and \(f\) has continuous second order derivatives.
    1. Verify that \(f(x,y) = x^2y + 2xy^2 + 5y^3\) is homogeneous of degree 3.
      🔗
      🔗
    2. Show that if \(f\) is homogeneous of degree \(n\) then
      \begin{equation*} x\,\frac{\partial f}{\partial x} + y\,\frac{\partial f}{\partial y} = n f(x,y). \end{equation*}
      (Hint: use the Chain Rule to differentiate \(f(tx,ty)\) with respect to \(t\text{.}\))
      🔗
      🔗
    3. If \(f\) is homogeneous of degree \(n\text{,}\) show that \(f_x(tx, ty) = t^{n-1} f_x(x,y)\) for \(t \gt 0\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    1. \begin{align*} f(tx, ty) \amp = t^2x^2\,ty + 2tx\,t^2y^2 + 5t^3y^3\\ \amp = t^3\left(x^2y + 2xy^2 + 5y^3\right) = t^3 f(x,y). \end{align*}
      🔗
      🔗
    2. Using the chain rule we obtain
      \begin{align} \frac{d}{dt}f(tx,ty) \amp = \frac{\partial f}{\partial x}(tx,ty)\,\frac{d}{dt}tx + \frac{\partial f}{\partial y}(tx,ty)\,\frac{d}{dt}ty\notag\\ \amp = x\,\frac{\partial f}{\partial x}(tx,ty) + y\,\frac{\partial f}{\partial y}(tx,ty).\tag{5.11.2} \end{align}
      On the other hand, the homogeneity condition (5.11.1) shows that
      \begin{equation} \frac{d}{dt}f(tx,ty) = \frac{d}{dt}\,t^n f(x,y) = n t^{n-1} f(x,y).\tag{5.11.3} \end{equation}
      Now we can equate the right hand sides of equations (5.11.2) and (5.11.3) and set \(t = 1\) to obtain the desired equation.
      🔗
      🔗
    3. We take the partial \(u\)-derivative of both sides of the equation \(f(tu, tv) = t^n f(u,v)\) (this is just (5.11.1) plugging in \(u\) and \(v\) instead of \(x\) and \(y\)):
      \begin{align*} \frac{\partial}{\partial u}\,t^n f(u,v) \amp = t^n f_x(u,v)\\ \frac{\partial}{\partial u}\,f(tu, tv) \amp = t\,f_x(tu, tv) \end{align*}
      Hence \(t^{n-1} f_x(u,v) = f_x(tu, tv)\) after canceling one \(t\text{,}\) and plugging in \(u = x\text{,}\) \(v = y\) shows the desired equation.
      🔗
      🔗
    🔗
    🔗

    4.

    Let
    \begin{equation*} w = 5xy + 2yz - 3xz, \qquad x = st, \qquad y = e^{st}, \qquad z = t^2. \end{equation*}
    Compute \(\dfrac{\partial w}{\partial s}(-4,-4)\) and \(\dfrac{\partial w}{\partial t}(-4,-4)\text{.}\)
    🔗
    Solution.
    The dependency tree is shown in Figure 5.11.55. We first compute
    \begin{equation*} \frac{\partial w}{\partial x} = 5y - 3z, \qquad \frac{\partial w}{\partial y} = 5x + 2z, \qquad \frac{\partial w}{\partial z} = 2y - 3x, \end{equation*}
    and at \((s,t) = (-4,-4)\) we have
    \begin{equation*} x(-4,-4) = 16, \qquad y(-4,-4) = e^{16}, \qquad z(-4,-4) = 16. \end{equation*}
    🔗
    By the chain rule, since \(\dfrac{\partial z}{\partial s} = 0\text{,}\)
    \begin{align*} \frac{\partial w}{\partial s} \amp = \frac{\partial w}{\partial x}\frac{\partial x}{\partial s} + \frac{\partial w}{\partial y}\frac{\partial y}{\partial s} + \frac{\partial w}{\partial z}\frac{\partial z}{\partial s}\\ \amp = (5y - 3z)(t) + (5x + 2z)\left(t e^{st}\right) + (2y - 3x)(0)\\ \amp = \left(5e^{16} - 48\right)(-4) + (80 + 32)\left(-4e^{16}\right)\\ \amp = -20e^{16} + 192 - 448e^{16} = -468e^{16} + 192. \end{align*}
    Similarly,
    \begin{align*} \frac{\partial w}{\partial t} \amp = \frac{\partial w}{\partial x}\frac{\partial x}{\partial t} + \frac{\partial w}{\partial y}\frac{\partial y}{\partial t} + \frac{\partial w}{\partial z}\frac{\partial z}{\partial t}\\ \amp = (5y - 3z)(s) + (5x + 2z)\left(s e^{st}\right) + (2y - 3x)(2t)\\ \amp = \left(5e^{16} - 48\right)(-4) + (112)\left(-4e^{16}\right) + \left(2e^{16} - 48\right)(-8)\\ \amp = -20e^{16} + 192 - 448e^{16} - 16e^{16} + 384 = -484e^{16} + 576. \end{align*}

    5.

    Consider \(f(x,y) = e^{-r^4}\) where \(r = \sqrt{x^2+y^2}\text{.}\) Compute its directional derivative at \((0,0)\) with respect to the unit vectors in (polar) directions \(\theta = 0, \dfrac{\pi}{4}, \dfrac{\pi}{2}\text{.}\) What about any other angle?
    🔗
    Solution.
    The function is symmetric with respect to rotations around the origin, so all the directional derivatives will be equal. Therefore it is sufficient to compute the derivative for \(\theta = 0\text{,}\) i.e. \(\dfrac{\partial f}{\partial x}\text{:}\)
    \begin{equation*} \frac{\partial f}{\partial x} = \frac{\partial}{\partial x} e^{-(x^2+y^2)^2} = -2(x^2+y^2)\cdot 2x\, e^{-(x^2+y^2)^2}. \end{equation*}
    Plugging in \(x = y = 0\) we see that this is zero. Hence the directional derivative at \((0,0)\) is \(0\) in the directions \(\theta = 0, \dfrac{\pi}{4}, \dfrac{\pi}{2}\text{,}\) and by the same symmetry it is \(0\) for every other angle as well.

    6. True or False.

      If \(\hat{u} = \langle a, b\rangle\) is a unit vector and \(f\) has continuous second partials, then
      \begin{equation*} D^2_{\hat{u}} f(x,y) = f_{xx}a^2 + 2f_{xy}ab + f_{yy}b^2, \end{equation*}
      where \(D^2_{\hat{u}} f = D_{\hat{u}}\left[D_{\hat{u}} f(x,y)\right]\text{.}\)
      🔗
      Justify your answer fully: give a proof if the statement is true, or a counterexample if it is false.
      🔗

    • True.

    • We have that
      \begin{equation*} D^2_{\hat{u}} f = D_{\hat{u}}\left[D_{\hat{u}} f(x,y)\right] = D_{\hat{u}}\left[a f_x + b f_y\right]. \end{equation*}
      This simplifies to
      \begin{equation*} \langle a f_{xx} + b f_{xy},\; a f_{xy} + b f_{yy}\rangle \cdot \langle a, b\rangle = f_{xx}a^2 + 2f_{xy}ab + f_{yy}b^2. \end{equation*}
      Note we needed \(f\) to have continuous second partials to invoke Clairaut’s Theorem.

    • False.

    • We have that
      \begin{equation*} D^2_{\hat{u}} f = D_{\hat{u}}\left[D_{\hat{u}} f(x,y)\right] = D_{\hat{u}}\left[a f_x + b f_y\right]. \end{equation*}
      This simplifies to
      \begin{equation*} \langle a f_{xx} + b f_{xy},\; a f_{xy} + b f_{yy}\rangle \cdot \langle a, b\rangle = f_{xx}a^2 + 2f_{xy}ab + f_{yy}b^2. \end{equation*}
      Note we needed \(f\) to have continuous second partials to invoke Clairaut’s Theorem.

    7. A mountain lion on a mountain.

    A mountain lion runs on a mountain whose height above the point \((x,y)\) is \(z = x^2 + \sin^2(xy)\text{.}\)
    1. In which direction(s) should the mountain lion run from point \((1, 0, 1)\) so that the height is increasing at the fastest possible rate? What is this fastest rate?
      🔗
      🔗
    2. In which direction(s) should the mountain lion run from point \((1, 0, 1)\) so that the height is increasing at half of the fastest possible rate?
      🔗
      🔗
    🔗
    Solution.
    1. The fastest possible rate of increase is attained in the direction of the gradient:
      \begin{equation*} \nabla z = \left\langle \frac{\partial z}{\partial x}, \frac{\partial z}{\partial y}\right\rangle = \left\langle 2x + 2\sin(xy)\cos(xy)\,y,\; 2\sin(xy)\cos(xy)\,x\right\rangle. \end{equation*}
      At \((1, 0, 1)\text{,}\) this gradient is simply \(\nabla z(1,0) = \langle 2, 0\rangle\text{,}\) and the fastest possible rate of change is the length of the gradient, i.e. \(\|\nabla z(1,0)\| = \|\langle 2,0\rangle\| = 2\text{.}\)
      🔗
      🔗
    2. Half of the fastest possible rate of height increase at point \((1,0,1)\) is \(\frac12 \cdot 2 = 1\text{.}\) Let \(\hat{u} = \langle a, b\rangle\) be a unit vector in the desired direction. Then the directional derivative \(D_{\hat{u}}(1,0) = 1\) is the desired rate of change of height at \((1,0,1)\) in the direction of \(\hat{u}\text{;}\) it can be calculated using the dot product with the gradient:
      \begin{equation*} 1 = D_{\hat{u}}(1,0) = \hat{u} \cdot \nabla z(1,0) = \langle a, b\rangle \cdot \langle 2, 0\rangle = 2a + 0b = 2a. \end{equation*}
      Thus, \(a = \frac12\) and \(b\) must be such that \(\hat{u} = \left\langle \frac12, b\right\rangle\) is unit, i.e. \(\left(\frac12\right)^2 + b^2 = 1\text{,}\) from which \(b^2 = \frac34\) and \(b = \pm\frac{\sqrt3}{2}\text{.}\) Therefore, the desired directions in which the height is increasing at a rate equal to half of the fastest possible rate are \(\hat{u}_1 = \left\langle \frac12, \frac{\sqrt3}{2}\right\rangle\) and \(\hat{u}_2 = \left\langle \frac12, -\frac{\sqrt3}{2}\right\rangle\text{.}\)
      🔗
      🔗
    🔗
    🔗

    8.

    Suppose that \(f(x,y)\) is a function of two variables and let
    \begin{equation*} \hat u = \frac{1}{\sqrt2}\langle 1, -1\rangle, \qquad \hat v = \langle 0, 1\rangle. \end{equation*}
    Suppose that at a point \(P_0(a,b)\text{,}\)
    \begin{align*} \left(D_{\hat u} f\right)_{P_0} \amp = 0,\\ \left(D_{\hat v} f\right)_{P_0} \amp = 1. \end{align*}
    1. Find the direction of the maximum rate of change at \(P_0(a,b)\text{.}\)
      🔗
      🔗
    2. Find the maximum rate of change at \(P_0(a,b)\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    1. Using \(\left(D_{\hat u} f\right)_{P_0} = \nabla f\big|_{P_0}\cdot\hat u\text{,}\) the two conditions become
      \begin{gather*} \left(D_{\hat u} f\right)_{P_0} = 0 \;\Rightarrow\; \langle f_x, f_y\rangle \cdot \frac{1}{\sqrt2}\langle 1, -1\rangle = \frac{1}{\sqrt2}\left(f_x - f_y\right) = 0\\ \qquad \Rightarrow\; f_x = f_y,\\ \left(D_{\hat v} f\right)_{P_0} = 1 \;\Rightarrow\; \langle f_x, f_y\rangle \cdot \langle 0, 1\rangle = f_y = 1. \end{gather*}
      Hence \(\nabla f\big|_{P_0} = \langle 1, 1\rangle\text{,}\) and the direction of the maximum rate of change at \(P_0\) is given by
      \begin{equation*} \hat u = \frac{\nabla f\big|_{P_0}}{\left\|\nabla f\big|_{P_0}\right\|} = \frac{1}{\sqrt2}\langle 1, 1\rangle. \end{equation*}
      🔗
      🔗
    2. \(\left\|\nabla f\big|_{P_0}\right\| = \sqrt{1 + 1} = \sqrt2\) is the maximum rate of change.
      🔗
      🔗

    9.

    Consider the function \(f(x,y) = x^2 e^{3y}\) and the point \(P_0 = (-1, 0)\text{.}\)
    1. Find the direction in which \(f(x,y)\) decreases the most rapidly at \(P_0\text{.}\)
      🔗
      🔗
    2. Find the directional derivative of \(f(x,y)\) at \(P_0\) in the direction given by \(\overrightarrow{v} = \langle -1, 1\rangle\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    The gradient is
    \begin{align*} \nabla f \amp = \left(2x e^{3y}\right)\hat{\imath} + \left(3x^2 e^{3y}\right)\hat{\jmath},\\ \nabla f\big|_{(-1,0)} \amp = -2\,\hat{\imath} + 3\,\hat{\jmath}, \qquad \left\|\nabla f\big|_{(-1,0)}\right\| = \sqrt{13}. \end{align*}
    1. The direction of most rapid decrease is opposite to the gradient:
      \begin{equation*} -\frac{\nabla f}{\|\nabla f\|} = \left(\frac{2}{\sqrt{13}}\right)\hat{\imath} - \left(\frac{3}{\sqrt{13}}\right)\hat{\jmath} = \left\langle \frac{2}{\sqrt{13}}, -\frac{3}{\sqrt{13}} \right\rangle. \end{equation*}
      🔗
      🔗
    2. The unit vector in the direction of \(\overrightarrow{v}\) is \(\hat u = \dfrac{\overrightarrow{v}}{\|\overrightarrow{v}\|} = \left\langle -\dfrac{1}{\sqrt2}, \dfrac{1}{\sqrt2}\right\rangle\text{,}\) so
      \begin{equation*} D_{\hat u} f = \nabla f \cdot \hat u = \langle -2, 3\rangle \cdot \left\langle -\frac{1}{\sqrt2}, \frac{1}{\sqrt2}\right\rangle = \frac{5}{\sqrt2}. \end{equation*}
      🔗
      🔗
    🔗
    🔗

    10.

    Suppose the temperature (in degrees Celsius) at a point \((x,y)\) is given by \(T(x,y)\text{,}\) where \(T\) is a continuous function that has continuous partial derivatives, and distances in the \(xy\)-plane are measured in meters. We are given the following information about \(T\) at the point \((x,y) = (1,1)\text{:}\)
    • \(T(1,1) = 20\) °C,
      🔗
      🔗
    • the derivative of \(T\) at \((1,1)\) obtains its smallest (i.e. most negative) value in the direction toward the point \((-1, 2)\text{,}\)
      🔗
      🔗
    • the derivative of \(T\) at \((1,1)\) in the direction of the vector \(4\,\hat{\imath} + 3\,\hat{\jmath}\) is \(3\) °C/m.
      🔗
      🔗
    1. Find the derivative of \(T\) at \((1,1)\) in the direction toward the point \((4,-3)\text{.}\)
      🔗
      🔗
    2. If you start at \((1,1)\) and move along a straight path toward the point \((4,-3)\text{,}\) approximately how far will you have to go in this direction until the temperature reaches \(24\) °C?
      🔗
      🔗
    🔗
    Solution.
    First we determine \(\nabla T\) at \((1,1)\text{.}\) The derivative is most negative in the direction of \(-\nabla T\text{,}\) and the direction from \((1,1)\) toward \((-1,2)\) is
    \begin{equation*} \langle -1-1,\; 2-1\rangle = \langle -2, 1\rangle. \end{equation*}
    Hence \(-\nabla T\) is a positive multiple of \(\langle -2, 1\rangle\text{,}\) i.e. \(\nabla T = c\,\langle 2, -1\rangle\) for some \(c \gt 0\text{.}\)
    🔗
    The third piece of information fixes \(c\text{.}\) The unit vector in the direction of \(4\,\hat{\imath} + 3\,\hat{\jmath}\) is \(\frac15\langle 4, 3\rangle\text{,}\) since \(\|\langle 4,3\rangle\| = 5\text{,}\) so
    \begin{equation*} 3 = \nabla T \cdot \frac15\langle 4, 3\rangle = \frac{c}{5}\Big(8 - 3\Big) = c \;\Rightarrow\; c = 3. \end{equation*}
    Therefore
    \begin{equation*} \nabla T\big|_{(1,1)} = 3\langle 2, -1\rangle = \langle 6, -3\rangle. \end{equation*}
    🔗
    1. The direction from \((1,1)\) toward \((4,-3)\) is \(\langle 3, -4\rangle\text{,}\) whose length is \(5\text{,}\) so the unit vector is \(\hat u = \left\langle \frac35, -\frac45\right\rangle\) and
      \begin{equation*} \left(D_{\hat u} T\right)_{(1,1)} = \langle 6, -3\rangle \cdot \left\langle \frac35, -\frac45\right\rangle = \frac{18}{5} + \frac{12}{5} = 6 \; {}^{\circ}\text{C}/\text{m}. \end{equation*}
      🔗
      🔗
    2. The temperature must rise from \(20\) °C to \(24\) °C, i.e. \(\Delta T = 4\) °C, and along this direction it rises at approximately \(6\) °C per meter. Using the linear approximation \(\Delta T \approx \left(D_{\hat u}T\right) \cdot s\text{,}\) where \(s\) is the distance travelled,
      \begin{equation*} s \approx \frac{\Delta T}{D_{\hat u}T} = \frac46 = \frac23 \approx 0.67 \text{ meters}. \end{equation*}
      🔗
      🔗

    11.

    \(f\) is a “nice” function of \(x\) and \(y\) (i.e. \(f\) is continuous and its partials exist). In Figure 5.11.56 are shown the level curves \(f(x,y) = 0, 2, 4, 6, 8, 10, 12\text{.}\)
    1. Let \(u_1 = \frac{1}{\sqrt2}\hat{\imath} + \frac{1}{\sqrt2}\hat{\jmath}\text{.}\) Estimate \(D_{u_1}f(4,3)\text{.}\)
      🔗
      🔗
    2. Estimate \(D_{u_1}f(1,2)\text{.}\)
      🔗
      🔗
    3. Draw on the diagram a unit vector pointing in the same direction as \(\nabla f(1,2)\text{.}\)
      🔗
      🔗
    4. At \(P\text{,}\) draw a unit vector and label it \(u_2\text{,}\) such that \(D_{u_2}f(P) \lt 0\text{.}\)
      🔗
      🔗
    5. Estimate \(\dfrac{\partial f}{\partial x}(P)\text{.}\)
      🔗
      🔗
    6. Which appears bigger, \(\dfrac{\partial f}{\partial y}(Q)\) or \(\dfrac{\partial f}{\partial y}(R)\text{?}\)
      🔗
      🔗
    🔗
    Solution.
    1. The directional derivative \(D_{u_1}f(4,3)\) tells us roughly how much \(f\) increases if we move one unit from \((4,3)\) in the direction \(u_1\text{,}\) i.e. diagonally up and to the right at \(45^{\circ}\text{.}\) Starting at \((4,3)\) and moving one unit that way lands us near \((4.7, 3.7)\text{,}\) which is about two contours further along, and each contour step is \(\Delta f = 2\) spread over roughly one unit of travel. Reading the map,
      \begin{equation*} D_{u_1}f(4,3) \approx 2. \end{equation*}
      🔗
      🔗
    2. At \((1,2)\) the level curve through that point is climbing at roughly \(45^{\circ}\text{,}\) i.e. the level curve is parallel to \(u_1\text{.}\) Moving along a level curve does not change the value of \(f\text{,}\) so
      \begin{equation*} D_{u_1}f(1,2) \approx 0. \end{equation*}
      🔗
      🔗
    3. The gradient is perpendicular to the level curve and points in the direction of increase. At \((1,2)\) the level curve runs up and to the right at about \(45^{\circ}\text{,}\) and \(f\) increases as we move upward, so \(\nabla f(1,2)\) points up and to the left, i.e. in the direction \(\frac{1}{\sqrt2}\langle -1, 1\rangle\text{.}\) See Figure 5.11.57.
      🔗
      🔗
    4. We need any direction of decrease at \(P\text{,}\) i.e. any direction pointing toward the lower-valued level curves (toward \(f = 10\text{,}\) not away from it). Since the level curves below \(P\) have smaller values, \(u_2 = \langle 0, -1\rangle\) (straight down) works. See Figure 5.11.57.
      🔗
      🔗
    5. \(P\) sits at the very top of its level curve, where the curve is horizontal. Walking in the \(+x\) direction from \(P\) therefore keeps us on the same level curve for a while, so \(f\) does not change to first order:
      \begin{equation*} \frac{\partial f}{\partial x}(P) \approx 0. \end{equation*}
      🔗
      🔗
    6. \(\dfrac{\partial f}{\partial y}\) measures how fast \(f\) changes as we move straight up, which is large where the contours are close together and small where they are far apart. At \(Q\) we only have to go up about \(0.25\) units to move from one contour to the next, so \(\dfrac{\partial f}{\partial y}(Q) \approx \dfrac{2}{0.25} = 8\text{.}\) At \(R\) we must go up about \(1\) unit for the same change, so \(\dfrac{\partial f}{\partial y}(R) \approx \dfrac{2}{1} = 2\text{.}\) Hence \(\dfrac{\partial f}{\partial y}(Q)\) is bigger.
      🔗
      🔗

    12. Electric Potential on a Coated Plate.

    The electric potential on a thin coated plate, in volts, is
    \begin{equation*} V(x,y) = 100 - 2x^2 - 6y^2, \end{equation*}
    with \(x\) and \(y\) in centimeters. Consider the point \(P_0(2,1)\text{.}\)
    🔗
    1. Find \(\nabla V\) at \(P_0\) and the electric field \(\mathbf E = -\nabla V\) there. Along which unit vector does the potential drop most rapidly, and at what rate?
      🔗
      🔗
    2. A test charge is nudged along \(\hat{u} = \tfrac{4}{5}\hat{\imath} - \tfrac{3}{5}\hat{\jmath}\text{.}\) Compute \(D_{\hat{u}}V\) at \(P_0\text{.}\)
      🔗
      🔗
    3. Find the two unit vectors along which the potential does not change, and name the curve they are tangent to.
      🔗
      🔗
    🔗
    Answer.
    1. \(\nabla V = -4x\,\hat{\imath} - 12y\,\hat{\jmath}\text{,}\) so \((\nabla V)_{(2,1)} = -8\,\hat{\imath} - 12\,\hat{\jmath}\) and \(\mathbf E = 8\,\hat{\imath} + 12\,\hat{\jmath}\) V/cm. The potential drops fastest along \(\hat{u} = \tfrac{1}{\sqrt{13}}(2\,\hat{\imath} + 3\,\hat{\jmath})\text{,}\) at the rate \(-\|\nabla V\| = -4\sqrt{13} \approx -14.4\) V/cm.
      🔗
      🔗
    2. \begin{equation*} D_{\hat{u}}V = (-8)\left(\tfrac{4}{5}\right) + (-12)\left(-\tfrac{3}{5}\right) = \tfrac{4}{5} = 0.8 \end{equation*}
      in V/cm. The potential rises slightly along this heading.
      🔗
      🔗
    3. \(\hat{u} = \pm\tfrac{1}{\sqrt{13}}(3\,\hat{\imath} - 2\,\hat{\jmath})\text{.}\) These are tangent to the equipotential ellipse \(2x^2 + 6y^2 = 14\) through \(P_0\text{,}\) and they are orthogonal to \(\mathbf E\text{,}\) as they must be.
      🔗

    13. Sailing the Isobars of a Low.

    Near the center of a low-pressure system the sea-level pressure, in millibars, is modeled by
    \begin{equation*} P(x,y) = 988 + 0.004\left(x^2 + y^2\right), \end{equation*}
    with \(x\) and \(y\) in miles from the center of the low. A ship sits at \(P_0(20,10)\text{.}\)
    🔗
    1. Find the pressure at the ship and \(\nabla P\) there. The pressure-gradient force per unit volume of air is a positive multiple of \(-\nabla P\text{;}\) in which unit direction does it push, and what is \(\|\nabla P\|\) in millibars per mile?
      🔗
      🔗
    2. A second ship 40 miles from the center reports a stronger wind. Using this model, explain why \(\|\nabla P\|\) supports that report.
      🔗
      🔗
    3. The captain decides to hold a constant barometer reading. Give the two possible unit headings at \(P_0\text{,}\) and describe the shape of the full route.
      🔗
      🔗
    🔗
    Answer.
    1. \(P(20,10) = 988 + 0.004(500) = 990\) mb, and \(\nabla P = 0.008x\,\hat{\imath} + 0.008y\,\hat{\jmath}\) gives \((\nabla P)_{(20,10)} = 0.16\,\hat{\imath} + 0.08\,\hat{\jmath}\text{.}\) The force points along \(-\mathbf u = -\tfrac{1}{\sqrt{5}}(2\,\hat{\imath} + \hat{\jmath})\text{,}\) that is, inward toward the low, and \(\|\nabla P\| = 0.08\sqrt{5} \approx 0.18\) mb/mi.
      🔗
      🔗
    2. Here \(\|\nabla P\| = 0.008\sqrt{x^2+y^2}\) grows linearly with distance from the center, so at 40 miles it is \(0.32\) mb/mi, nearly double the value at the first ship. (Real storms reverse this trend close to the eye; the model is only reasonable over a limited annulus.)
      🔗
      🔗
    3. \(\mathbf u = \pm\tfrac{1}{\sqrt{5}}(\hat{\imath} - 2\,\hat{\jmath})\text{.}\) Since the level curves of \(P\) are the circles \(x^2+y^2 = \text{constant}\text{,}\) holding the barometer steady means circling the storm at a fixed radius of \(\sqrt{500} \approx 22.4\) miles.
      🔗
      🔗
