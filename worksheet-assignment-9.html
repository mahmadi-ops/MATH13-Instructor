    Worksheet 5.12 Assignment 9
    

    These problems find the tangent plane to a graph and lines lying in it, show that the radius of a sphere is orthogonal to its tangent plane, and use differentials to estimate a change in a function and to approximate a value. If you would like to review the material first, see Tangent Planes and Differentials.
    🔗

    1.

    Find an equation for the tangent plane to the graph of \(f(x,y) = \cos(xy)\) passing through the point \(\left(\dfrac{\pi}{2}, 1, 0\right)\text{.}\)
    🔗
    Solution.
    We have \(f_x = -y\sin(xy)\) and \(f_y = -x\sin(xy)\text{,}\) so the tangent plane at a general point \((x_0, y_0)\) is given by
    \begin{equation*} z - \cos(x_0 y_0) = -y_0 \sin(x_0 y_0)(x - x_0) - x_0 \sin(x_0 y_0)(y - y_0). \end{equation*}
    🔗
    Plugging in our point \(\left(\dfrac{\pi}{2}, 1, 0\right)\text{,}\) this becomes
    \begin{equation*} z = -1\cdot\left(x - \frac{\pi}{2}\right) - \frac{\pi}{2}\cdot(y - 1), \end{equation*}
    or equivalently
    \begin{equation*} x + \frac{\pi}{2}\,y + z = \pi. \end{equation*}
    🔗
    🔗
    🔗

    2.

    Find a parametric equation for a line contained in the tangent plane you found in the previous problem. (Any line will suffice.)
    🔗
    Solution.
    Note that the point \(\left(\dfrac{\pi}{2}, 1, 0\right)\) lies on this plane, and the plane has normal vector \(\vec n = \left\langle 1, \dfrac{\pi}{2}, 1\right\rangle\text{.}\) Any vector orthogonal to the normal vector will point along this plane. By inspection, we see that
    \begin{equation*} \langle 1, 0, -1\rangle \cdot \left\langle 1, \frac{\pi}{2}, 1\right\rangle = 0, \end{equation*}
    so the vector \(\langle 1, 0, -1\rangle\) points along the plane. Thus \(\langle 1, 0, -1\rangle\) is the direction vector of a line pointing along this plane. Combining this with the point on the plane that we have already found, we see that the line
    \begin{equation*} \mathbf r(t) = \left\langle t + \frac{\pi}{2},\; 1,\; -t\right\rangle \end{equation*}
    is contained in the tangent plane. We could find other lines contained in the plane by making different choices of direction vector. See Figure 5.12.60.
    🔗
    🔗
    🔗

    3.

    Find the equation of the tangent plane at the point \(P_0(2,0,2)\) on the surface \(2z - x^2 = 0\text{.}\)
    🔗
    Solution.
    Let \(w(x,y,z) = 2z - x^2 = 0\text{.}\) Then
    \begin{equation*} \nabla w = (-2x)\,\mathbf i + 2\,\mathbf k, \end{equation*}
    and the normal to the tangent plane is
    \begin{equation*} \vec n = \nabla w\big|_{P_0} = -4\,\mathbf i + 2\,\mathbf k. \end{equation*}
    The constant is
    \begin{equation*} D = \vec n \cdot \vec{OP_0} = \langle -4, 0, 2\rangle \cdot \langle 2, 0, 2\rangle = -8 + 4 = -4, \end{equation*}
    so from \(Ax + By + Cz = D\text{,}\) the tangent plane at \(P_0(2,0,2)\) is
    \begin{equation*} -4x + 2z = -4 \qquad\text{or}\qquad 2x - z = 2. \end{equation*}
    🔗
    🔗

    4. True or False.

      Any tangent plane to a graph must meet that graph at exactly one point.
      🔗
      Justify your answer fully: give a proof if the statement is true, or a counterexample if it is false.
      🔗

    • True.

    • Consider the plane \(z = c\text{.}\) The tangent plane to this graph at any point is the same as \(z = c\text{,}\) so it meets the graph at infinitely many points.

    • False.

    • Consider the plane \(z = c\text{.}\) The tangent plane to this graph at any point is the same as \(z = c\text{,}\) so it meets the graph at infinitely many points.

    5.

    Let \(S\) be a sphere centered at the origin in \(\R^3\text{,}\) and consider any point \(P\) on \(S\text{.}\) Show that the vector \(\vec{OP}\) is orthogonal to the tangent plane to \(S\) at \(P\text{.}\)
    🔗
    Solution.
    Let \(R\) be the radius of the sphere, and write \(P = (x_0, y_0, z_0)\text{.}\) Assume for the moment that \(P\) lies on the top half of the sphere (i.e. \(z_0 \gt 0\)). Note that the top half of the sphere is the same as the graph of the function \(f(x,y) = \sqrt{R^2 - x^2 - y^2}\text{.}\) We can compute
    \begin{align*} \frac{\partial f}{\partial x}(x_0, y_0) \amp = -\frac{x_0}{\sqrt{R^2 - x_0^2 - y_0^2}},\\ \frac{\partial f}{\partial y}(x_0, y_0) \amp = -\frac{y_0}{\sqrt{R^2 - x_0^2 - y_0^2}}, \end{align*}
    so that the tangent plane to the graph at \(P\) (which is the same as the tangent plane to \(S\) at \(P\)) is given by
    \begin{equation*} z - z_0 = -\frac{x_0}{\sqrt{R^2 - x_0^2 - y_0^2}}\,(x - x_0) - \frac{y_0}{\sqrt{R^2 - x_0^2 - y_0^2}}\,(y - y_0). \end{equation*}
    🔗
    We can rewrite this as
    \begin{equation*} x_0(x - x_0) + y_0(y - y_0) + z_0(z - z_0) = 0, \end{equation*}
    where we use the fact that \(z_0 = \sqrt{R^2 - x_0^2 - y_0^2}\) to simplify things. From this we see that \(\langle x_0, y_0, z_0\rangle\) is a normal vector to the tangent plane. But \(\langle x_0, y_0, z_0\rangle = \vec{OP}\text{,}\) so this is exactly what we needed to show. See Figure 5.12.61.
    🔗
    A similar argument (with \(-\sqrt{R^2 - x^2 - y^2}\) in place of \(\sqrt{R^2 - x^2 - y^2}\)) works when \(P\) is on the bottom half of the sphere (i.e. \(z_0 \lt 0\)). When \(z_0 = 0\text{,}\) we have to use a “sideways graph” of some function like \(f(y,z) = \sqrt{R^2 - y^2 - z^2}\text{,}\) but other than that, pretty much everything is the same.
    🔗

    6.

    Find the equation of the tangent plane to the sphere \(x^2 + y^2 + z^2 = 14\) at \((1,2,3)\text{.}\)
    🔗
    Solution.
    Write the sphere as the level surface \(F(x,y,z) = x^2 + y^2 + z^2 = 14\text{.}\) The gradient is normal to the level surface:
    \begin{equation*} \nabla F = \langle 2x, 2y, 2z\rangle, \qquad \vec n = \nabla F\big|_{(1,2,3)} = \langle 2, 4, 6\rangle. \end{equation*}
    Hence the tangent plane is
    \begin{equation*} 2(x-1) + 4(y-2) + 6(z-3) = 0, \end{equation*}
    which simplifies to \(x + 2y + 3z = 14\text{.}\) (Notice that the normal vector is parallel to the position vector \(\langle 1,2,3\rangle\text{,}\) exactly as we proved for spheres centered at the origin.)
    🔗

    7.

    The tangent plane to \(z = f(x,y)\) at the point \((1,2,9)\) is \(z = 3x + 5y - 4\text{.}\) Find \(\nabla f(1,2)\text{.}\)
    🔗
    Solution.
    The tangent plane to the graph of \(f\) at \((a,b)\) is
    \begin{equation*} z = f(a,b) + f_x(a,b)(x-a) + f_y(a,b)(y-b), \end{equation*}
    so once it is expanded the coefficient of \(x\) is \(f_x(a,b)\) and the coefficient of \(y\) is \(f_y(a,b)\text{.}\) Comparing with \(z = 3x + 5y - 4\) gives
    \begin{equation*} f_x(1,2) = 3, \qquad f_y(1,2) = 5, \end{equation*}
    and therefore
    \begin{equation*} \nabla f(1,2) = 3\,\mathbf i + 5\,\mathbf j. \end{equation*}
    (As a check, the plane passes through \((1,2,9)\text{:}\) \(3(1) + 5(2) - 4 = 9\) \(\checkmark\text{.}\))

    8.

    Let \(f(x,y) = 2 + \ln(1 + 3x - 4y)\text{.}\) Use a linearization to approximate \(f(0.1, 0.2)\text{.}\)
    🔗
    Solution.
    The point \((0.1, 0.2)\) is close to the origin, where the function is easy to work with, so we linearize at \((0,0)\text{:}\)
    \begin{equation*} f(0,0) = 2 + \ln(1) = 2, \qquad f_x = \frac{3}{1+3x-4y}, \qquad f_y = \frac{-4}{1+3x-4y}, \end{equation*}
    so \(f_x(0,0) = 3\) and \(f_y(0,0) = -4\text{.}\) The linearization is
    \begin{equation*} L(x,y) = f(0,0) + f_x(0,0)x + f_y(0,0)y = 2 + 3x - 4y, \end{equation*}
    and therefore
    \begin{equation*} f(0.1, 0.2) \approx L(0.1, 0.2) = 2 + 0.3 - 0.8 = 1.5. \end{equation*}

    9.

    Let
    \begin{equation*} g(x,y) = \frac{\sqrt{x}}{\sqrt[3]{y}} , \end{equation*}
    and note that \(g(36,8) = 3\text{.}\) Use an appropriate partial derivative to approximate \(g(36,6)\text{.}\)
    🔗
    Solution.
    We move from \((36,8)\) to \((36,6)\text{.}\) Only \(y\) changes, and it changes by
    \begin{equation*} \Delta y = 6 - 8 = -2 , \end{equation*}
    so the partial derivative we need is \(g_y\text{.}\) Writing \(g(x,y) = x^{1/2} y^{-1/3}\text{,}\)
    \begin{equation*} g_y(x,y) = -\frac{1}{3}\, x^{1/2} y^{-4/3} = -\frac{\sqrt{x}}{3\, y^{4/3}} . \end{equation*}
    🔗
    At \((36,8)\) we have \(\sqrt{36} = 6\) and \(8^{4/3} = \left(8^{1/3}\right)^4 = 2^4 = 16\text{,}\) so
    \begin{equation*} g_y(36,8) = -\frac{6}{3 \cdot 16} = -\frac{6}{48} = -\frac{1}{8} . \end{equation*}
    🔗
    The linear approximation is
    \begin{align*} g(36,6) \amp \approx g(36,8) + g_y(36,8)\,\Delta y\\ \amp = 3 + \left(-\frac{1}{8}\right)(-2)\\ \amp = 3 + \frac14 = \frac{13}{4} = 3.25 . \end{align*}
    🔗
    As a check, the exact value is \(g(36,6) = 6/\sqrt[3]{6} \approx 3.302\text{,}\) so the approximation is good to about \(1.6\%\text{.}\)
