    Subsection 4.4.1 One Independent Variable

    Theorem 4.4.1. Chain Rule for Functions of Two Independent Variables.

    Consider the two-variable function \(w = f(x,y)\text{.}\) If the following conditions are satisfied:
    🔗
    1. \(w = f(x,y)\) has continuous partial derivatives \(f_x\) and \(f_y\text{,}\)
    🔗
    2. \(x = x(t)\) and \(y = y(t)\) are differentiable functions of \(t\text{,}\)
    🔗
    then the function \(w = f(x(t), y(t))\) is a differentiable function of \(t\) and
    \begin{equation} \frac{dw}{dt} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt}.\tag{4.4.1} \end{equation}
    🔗
    🔗
    Figure 4.4.2 provides an easy way to remember the chain rule. Note that \(w\) is the dependent variable since it depends on \(x\) and \(y\text{,}\) and \(x\) and \(y\) are known as the intermediate variables, whereas \(t\) is the independent variable. To use the diagram, read every path from \(w\) down to \(t\text{,}\) multiply the derivatives along each path, and add the results.
    🔗

    Theorem 4.4.3. Chain Rule for Functions of Three Independent Variables.

    Consider the three-variable function \(w = f(x,y,z)\text{.}\) If the following conditions are satisfied:
    🔗
    1. \(w = f(x,y,z)\) has continuous partial derivatives \(f_x\text{,}\) \(f_y\text{,}\) and \(f_z\text{,}\)
    🔗
    2. \(x = x(t)\text{,}\) \(y = y(t)\text{,}\) and \(z = z(t)\) are differentiable functions of \(t\text{,}\)
    🔗
    then the function \(w = f(x(t), y(t), z(t))\) is a differentiable function of \(t\) and
    \begin{equation} \frac{dw}{dt} = \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} + \frac{\partial f}{\partial z}\frac{dz}{dt}.\tag{4.4.2} \end{equation}
    🔗
    🔗
    Again the tree diagram of Figure 4.4.4 provides an easy way to remember the chain rule: now there are three paths from \(w\) down to \(t\text{,}\) so the formula has three terms.
    🔗

    Example 4.4.5. Differentiating Along a Circle.

    Consider the function \(w = f(x,y) = xy\text{,}\) where \(x = \cos t\) and \(y = \sin t\text{.}\) Evaluate \(\left.\dfrac{dw}{dt}\right|_{t=\pi/2}\text{.}\)
    🔗
    Solution.
    Method 1: using the chain rule. By (4.4.1),
    \begin{align*} \frac{dw}{dt} \amp= \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} = (y)(-\sin t) + (x)(\cos t)\\ \amp= (\sin t)(-\sin t) + (\cos t)(\cos t)\\ \amp= \cos^2 t - \sin^2 t = \cos(2t), \end{align*}
    and therefore
    \begin{equation*} \left.\frac{dw}{dt}\right|_{t=\pi/2} = \cos(\pi) = -1. \end{equation*}
    🔗
    Method 2: without using the chain rule. We can substitute first and then differentiate:
    \begin{align*} w = f(x,y) = xy \amp \;\Rightarrow\; w(t) = \cos t \sin t = \frac{1}{2}\sin(2t)\\ \amp \;\Rightarrow\; \frac{dw}{dt} = \cos(2t), \end{align*}
    so again
    \begin{equation*} \left.\frac{dw}{dt}\right|_{t=\pi/2} = \cos(\pi) = -1. \end{equation*}
    Note that the two results agree with each other.
    🔗
    Geometrically, the constraint \(x = \cos t\text{,}\) \(y = \sin t\) confines the point \((x,y)\) to the unit circle \(x^2+y^2 = 1\text{,}\) so the composition traces a curve on the saddle \(z = xy\text{,}\) as shown in Figure 4.4.6. The derivative \(\frac{dw}{dt}\) is the rate at which the height of that curve changes.
    🔗
    Figure 4.4.7 sets that picture moving. As \(t\) runs from \(0\) to \(2\pi\) the point travels once round the circle while the curve above it climbs and falls twice, and the readout carries both the height \(w\) and the rate \(\frac{dw}{dt} = \cos 2t\) the chain rule predicts. At \(t = \pi/2\) that rate reads \(-1\text{,}\) the answer computed above.
    🔗
    🔗
    🔗

    Example 4.4.8. A Second Application of the Chain Rule.

    Consider the function \(w = f(x,y) = xy + y^2\text{,}\) where \(x = \cos t\) and \(y = 1 + 2\sin t\text{.}\) Evaluate \(\left.\dfrac{dw}{dt}\right|_{t=\pi}\text{.}\)
    🔗
    Solution.
    By (4.4.1), with \(\frac{\partial f}{\partial x} = y\) and \(\frac{\partial f}{\partial y} = x + 2y\text{,}\)
    \begin{align*} \frac{dw}{dt} \amp= \frac{\partial f}{\partial x}\frac{dx}{dt} + \frac{\partial f}{\partial y}\frac{dy}{dt} = (y)(-\sin t) + (x+2y)(2\cos t)\\ \amp= (1+2\sin t)(-\sin t) + \bigl(\cos t + 2(1+2\sin t)\bigr)(2\cos t)\\ \amp= -\sin t - 2\sin^2 t + 2\cos^2 t + 4\cos t + 8 \sin t \cos t. \end{align*}
    At \(t = \pi\) we have \(\sin \pi = 0\) and \(\cos \pi = -1\text{,}\) so the surviving terms are \(2\cos^2 \pi = 2\) and \(4\cos \pi = -4\text{,}\) giving
    \begin{equation*} \left.\frac{dw}{dt}\right|_{t=\pi} = 2 - 4 = -2. \end{equation*}
