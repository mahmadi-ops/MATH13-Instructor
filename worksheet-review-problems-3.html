    1.

    Consider the function
    \begin{equation*} h(x,y,z) = z + \sqrt{x^2+y^2} + 1 . \end{equation*}
    Sketch the level surface of \(h\) that passes through the point \((3,4,-5)\text{.}\) Clearly label the value of \(h\) on that surface, and label the coordinate axes.
    🔗
    Solution.
    The level surfaces of \(h\) are the surfaces \(h(x,y,z) = c\text{.}\) To find which one passes through \((3,4,-5)\) we simply evaluate:
    \begin{align*} h(3,4,-5) \amp = -5 + \sqrt{3^2+4^2} + 1\\ \amp = -5 + \sqrt{25} + 1\\ \amp = -5 + 5 + 1 = 1 . \end{align*}
    So the level surface we want is \(h(x,y,z) = 1\text{.}\)
    🔗
    Now we simplify the equation of that level surface:
    \begin{align*} z + \sqrt{x^2+y^2} + 1 \amp = 1\\ z + \sqrt{x^2+y^2} \amp = 0\\ z \amp = -\sqrt{x^2+y^2} . \end{align*}
    🔗
    This is a cone. Indeed, squaring gives \(z^2 = x^2+y^2\text{,}\) which is the full double cone; but the equation \(z = -\sqrt{x^2+y^2}\) forces \(z \le 0\text{,}\) so we keep only the lower nappe. The vertex is at the origin, and the horizontal trace at height \(z = -k\) (with \(k \gt 0\)) is the circle \(x^2+y^2 = k^2\) of radius \(k\text{.}\) In other words the cone opens downwards, and the slope of every straight line drawn on it from the vertex is \(-1\text{.}\) The point \((3,4,-5)\) lies on it, since \(-\sqrt{3^2+4^2} = -5\text{.}\) See Figure 5.13.62.
    🔗
    🔗

    2.

    Sketch three level curves of
    \begin{equation*} h(x,y) = \frac{y^2}{x} , \end{equation*}
    including the one that passes through the point \((-1,2)\text{.}\) Clearly label the value of \(h\) on each curve.
    🔗
    Solution.
    First we find the level through \((-1,2)\text{:}\)
    \begin{equation*} h(-1,2) = \frac{2^2}{-1} = -4 . \end{equation*}
    So one of the three curves must be \(h(x,y) = -4\text{.}\)
    🔗
    In general the level curve \(h(x,y) = c\) is
    \begin{equation*} \frac{y^2}{x} = c \quad\Longleftrightarrow\quad y^2 = c\,x \quad\Longleftrightarrow\quad x = \frac{y^2}{c} \qquad (c \ne 0) . \end{equation*}
    Each of these is a parabola opening along the \(x\)-axis, with vertex at the origin. If \(c \gt 0\) it opens to the right, and if \(c \lt 0\) it opens to the left. Note that the domain of \(h\) excludes \(x = 0\text{,}\) so the vertex itself, the origin, must be removed from every level curve.
    🔗
    Let us take the three levels \(c = -4\text{,}\) \(c = 1\) and \(c = 4\text{:}\)
    \begin{align*} h \amp = -4: \amp\qquad x \amp = -\frac{y^2}{4} \amp\amp \text{(opens left)},\\ h \amp = 1: \amp\qquad x \amp = y^2 \amp\amp \text{(opens right, narrow)},\\ h \amp = 4: \amp\qquad x \amp = \frac{y^2}{4} \amp\amp \text{(opens right, wide)}. \end{align*}
    The larger \(|c|\) is, the wider the parabola. These are drawn in Figure 5.13.63.
    🔗
    One more remark: the level \(c = 0\) is special. There \(y^2 = 0\text{,}\) so the level curve \(h = 0\) is not a parabola at all but the \(x\)-axis with the origin removed.

    4.

    Show that the limit does not exist:
    \begin{equation*} \lim_{(x,y)\to(1,0)} \frac{x + y^2}{(x-1)^3 + y^4}. \end{equation*}
    🔗
    Solution.
    Approaching the limit along the \(x\)-axis, i.e. \(y = 0\text{,}\) we need to consider
    \begin{equation*} \lim_{x\to 1} \frac{x}{(x-1)^3}, \end{equation*}
    which does not exist since the numerator has limit \(1\) but the denominator has limit \(0\text{.}\)

    5.

    Evaluate the following limit or show that the limit does not exist:
    \begin{equation*} \lim_{(x,y)\to(0,0)} \frac{x^2 + y^4}{x^2 + y^2}. \end{equation*}
    🔗
    Solution.
    Along the line \(y = x\text{:}\)
    \begin{equation*} \lim_{(x,y)\to(0,0)} \frac{x^2 + y^4}{x^2 + y^2} = \lim_{x\to 0} \frac{x^2 + x^4}{2x^2} = \lim_{x\to 0} \frac12\left(1 + x^2\right) = \frac12. \end{equation*}
    Along the line \(y = 0\text{:}\)
    \begin{equation*} \lim_{(x,y)\to(0,0)} \frac{x^2 + y^4}{x^2 + y^2} = \lim_{x\to 0} \frac{x^2}{x^2} = 1. \end{equation*}
    Since \(1 \ne \frac12\text{,}\) the limit does not exist.
    🔗
    🔗
    🔗

    6.

    Show that the following limit does not exist:
    \begin{equation*} \lim_{(x,y)\to(0,0)} \frac{2x^2 y}{x^4 + y^2}. \end{equation*}
    🔗
    Solution.
    Along \(x = 0\text{,}\) we have
    \begin{equation*} f(0,y) = \frac{0}{0 + y^2} = 0, \end{equation*}
    hence \(f(x,y)\) approaches zero as \((x,y)\to(0,0)\) along the line \(x = 0\text{.}\) Along \(y = x^2\text{,}\) we have
    \begin{equation*} f\left(x, x^2\right) = \frac{2x^4}{x^4 + x^4} = \frac{x^4}{x^4} = 1, \end{equation*}
    and hence \(f(x,y) \to 1\) as \((x,y)\to(0,0)\) along \(y = x^2\text{.}\) Since the limits computed along two different paths are not equal, we can conclude that \(\lim\limits_{(x,y)\to(0,0)} f(x,y)\) does not exist.
    🔗

    7. True or False.

      🔗
      Justify your answer fully: give a proof if the statement is true, or a counterexample if it is false.
      🔗

    • True.

    • Counterexample:
      \begin{equation*} f(x,y) = x + y \quad\text{and}\quad g(x,y) = x^2 - y^2 \end{equation*}
      are both continuous at \((0,0)\text{.}\) However,
      \begin{equation*} \frac{f}{g} = \frac{x+y}{x^2 - y^2} = \frac{1}{x-y} \end{equation*}
      is not continuous at \((0,0)\text{,}\) since for example along \(y = 0\text{,}\)
      \begin{equation*} \lim_{(x,y)\to(0,0)} \frac{1}{x-y} = \lim_{x\to 0^{\pm}} \frac{1}{x} = \pm\infty. \end{equation*}

    • False.

    • Counterexample:
      \begin{equation*} f(x,y) = x + y \quad\text{and}\quad g(x,y) = x^2 - y^2 \end{equation*}

    8.

    A metal plate occupies the square \(0 \le x \le 5\text{,}\) \(0 \le y \le 5\text{,}\) and is heated so that the temperature at the point \((x,y)\) is \(T(x,y)\text{,}\) measured in degrees Fahrenheit. Distances are measured in feet. The table below records some measured values of \(T\text{.}\)
    🔗
    1. Approximate \(T_x(1,1)\) and interpret your answer, with units, in the context of the problem.
      🔗
      🔗
    2. Approximate \(T_{xy}(1,1)\text{,}\) and give its units.
      🔗
      🔗
    3. An ant walks across the plate along the path
      \begin{equation*} x = 1 - \frac{\ln(2t-3)}{4}, \qquad y = \frac{2^t}{4}, \qquad 1.5 \lt t \lt 4 . \end{equation*}
      Approximate the rate at which the temperature the ant feels is changing at the moment it is at the point \((x,y) = (1,1)\text{,}\) and give the units.
      🔗
      🔗
    🔗
    Solution.
    (a) Holding \(y=1\) and stepping forward in \(x\text{,}\)
    \begin{equation*} T_x(1,1) \approx \frac{T(1.5,1) - T(1,1)}{0.5} = \frac{65-70}{0.5} = -10 \quad {}^{\circ}\text{F}/\text{ft} . \end{equation*}
    So at \((1,1)\text{,}\) moving in the positive \(x\)-direction with \(y\) held fixed, the temperature drops at a rate of about \(10\,{}^{\circ}\text{F}\) per foot.
    🔗
    (b) We need \(T_x\) at a second value of \(y\text{:}\)
    \begin{equation*} T_x(1,1.5) \approx \frac{T(1.5,1.5) - T(1,1.5)}{0.5} = \frac{69-73}{0.5} = -8 . \end{equation*}
    Then
    \begin{equation*} T_{xy}(1,1) \approx \frac{T_x(1,1.5) - T_x(1,1)}{0.5} = \frac{-8-(-10)}{0.5} = 4 \quad {}^{\circ}\text{F}/\text{ft}^2 . \end{equation*}
    🔗
    (c) As in Worksheet Exercise 5.10.13, the ant is at \((1,1)\) when \(\ln(2t-3) = 0\text{,}\) that is at \(t = 2\text{,}\) and then \(y = 2^2/4 = 1\) as required. Differentiating the path,
    \begin{align*} \frac{dx}{dt} \amp = -\frac{1}{4}\cdot\frac{2}{2t-3} = -\frac{1}{2(2t-3)}, \amp \frac{dx}{dt}\bigg|_{t=2} \amp = -\frac{1}{2} ,\\ \frac{dy}{dt} \amp = \frac{2^t\ln 2}{4}, \amp \frac{dy}{dt}\bigg|_{t=2} \amp = \ln 2 . \end{align*}
    🔗
    From the table,
    \begin{equation*} T_y(1,1) \approx \frac{T(1,1.5)-T(1,1)}{0.5} = \frac{73-70}{0.5} = 6 . \end{equation*}
    🔗
    By the chain rule,
    \begin{align*} \frac{dT}{dt} \amp = T_x\,\frac{dx}{dt} + T_y\,\frac{dy}{dt}\\ \amp \approx (-10)\left(-\frac12\right) + (6)(\ln 2)\\ \amp = 5 + 6\ln 2 \approx 9.16 , \end{align*}
    in degrees Fahrenheit per unit of \(t\text{.}\) Here the ant is warming up: it moves in the \(-x\) direction, where the plate is hotter, and in the \(+y\) direction, where the plate is also hotter, so both contributions are positive. Compare this with Worksheet Exercise 5.10.13, where the same computation gave a negative rate.

    9.

    Let \(f(x,z) = x^2z + e^{xz + z^2}\) and \(x = r\cos(\theta)\text{,}\) \(z = r\sin(\theta)\text{.}\) Use the chain rule to compute \(\dfrac{\partial f}{\partial \theta}\) at \((r,\theta) = \left(3, \frac{\pi}{2}\right)\text{.}\)
    🔗
    Solution.
    The chain rule gives
    \begin{align*} \frac{\partial f}{\partial \theta} \amp = \frac{\partial f}{\partial x}\frac{\partial x}{\partial \theta} + \frac{\partial f}{\partial z}\frac{\partial z}{\partial \theta}\\ \amp = \left[2xz + z\,e^{xz+z^2}\right](-r\sin\theta)\\ \amp \quad + \left[x^2 + (x + 2z)e^{xz+z^2}\right](r\cos\theta). \end{align*}
    🔗
    At \((r,\theta) = \left(3, \frac{\pi}{2}\right)\) we have \(x = 3\cos\frac{\pi}{2} = 0\) and \(z = 3\sin\frac{\pi}{2} = 3\text{,}\) so \((x,z) = (0,3)\) and \(xz + z^2 = 0 + 9 = 9\text{.}\) Also \(-r\sin\theta = -3\) and \(r\cos\theta = 0\text{.}\) Hence
    \begin{equation*} \frac{\partial f}{\partial \theta} = \left[0 + 3e^{9}\right](-3) + \left[0 + 6e^{9}\right](0) = -9e^{9}. \end{equation*}

    10.

    Find all points at which the direction of fastest change of the function \(f(x,y) = x^2 + y^2 - 2x - 4y\) is \(\langle 1, 1\rangle\text{.}\)
    🔗
    Solution.
    The direction of fastest change is \(\nabla f(x,y) = \langle 2x-2,\, 2y-4\rangle\text{,}\) so we need to find all points \((x,y)\) such that \(\nabla f(x,y) = k\langle 1,1\rangle\text{.}\) Then
    \begin{equation*} 2x - 2 = k \quad\text{and}\quad 2y - 4 = k, \end{equation*}
    so
    \begin{equation*} 2x - 2 = 2y - 4 \;\Rightarrow\; y = x + 1. \end{equation*}
    Hence, the direction of fastest change is \(\langle 1,1\rangle\) at all points on the line \(y = x + 1\text{.}\) See Figure 5.13.65.

    12.

    A metal plate is placed on the \(xy\)-plane in such a way that the temperature \(T\) at any point \((x,y)\) is given by \(T = e^x(\sin x + \sin y)\) °C.
    1. What is the rate of change in temperature at \((0,0)\) in the direction of \(3\,\hat{\imath} - 4\,\hat{\jmath}\text{?}\)
      🔗
      🔗
    2. At \((0,0)\text{,}\) in what direction is the temperature increasing most rapidly?
      🔗
      🔗
    3. At \((0,0)\text{,}\) in what direction is the temperature decreasing most rapidly?
      🔗
      🔗
    🔗
    Solution.
    1. We first compute the gradient:
      \begin{align*} T_x \amp = e^x(\sin x + \sin y) + e^x\cos x\\ \amp = e^x(\sin x + \cos x + \sin y), \qquad T_x(0,0) = 1,\\ T_y \amp = e^x \cos y, \qquad T_y(0,0) = 1, \end{align*}
      so \(\nabla T\big|_{(0,0)} = \langle 1, 1\rangle\text{.}\) The direction vector is \(\overrightarrow{u} = \langle 3, -4\rangle\) with \(\|\overrightarrow{u}\| = \sqrt{9 + 16} = 5\text{,}\) so the unit vector is \(\hat u = \dfrac{\overrightarrow{u}}{\|\overrightarrow{u}\|} = \left\langle \dfrac35, -\dfrac45\right\rangle\text{.}\) Hence
      \begin{equation*} \left(D_{\hat u} T\right)_{(0,0)} = \nabla T\big|_{(0,0)} \cdot \hat u = \langle 1, 1\rangle \cdot \left\langle \frac35, -\frac45\right\rangle = -\frac15. \end{equation*}
      🔗
      🔗
    2. The temperature increases most rapidly in the direction of the gradient:
      \begin{equation*} \hat u = \frac{\nabla T\big|_{(0,0)}}{\left\|\nabla T\big|_{(0,0)}\right\|} = \left\langle \frac{1}{\sqrt2}, \frac{1}{\sqrt2}\right\rangle. \end{equation*}
      🔗
      🔗
    3. The temperature decreases most rapidly in the direction opposite to the gradient:

    13.

    Calculate the maximum rate of change of \(f(x,y) = \ln(x^2+y^2)\) at the point \((-4, 3)\) and determine the direction in which it occurs.
    🔗
    Solution.
    The gradient is
    \begin{equation*} \nabla f = \left(\frac{2x}{x^2+y^2}\right)\hat{\imath} + \left(\frac{2y}{x^2+y^2}\right)\hat{\jmath}, \end{equation*}
    so at \((-4,3)\text{,}\)
    \begin{align*} \nabla f(-4,3) \amp = \left(-\frac{8}{25}\right)\hat{\imath} + \left(\frac{6}{25}\right)\hat{\jmath},\\ \|\nabla f(-4,3)\| \amp = \sqrt{\frac{100}{(25)^2}} = \frac{10}{25} = \frac25. \end{align*}
    The direction of maximum increase is
    \begin{equation*} \hat u = \frac{\nabla f(-4,3)}{\|\nabla f(-4,3)\|} = \left(-\frac45\right)\hat{\imath} + \left(\frac35\right)\hat{\jmath}, \end{equation*}
    and the maximum rate of increase is
    \begin{equation*} \left(D_{\hat u} f\right)_{P_0} = \|\nabla f(-4,3)\| = \frac25. \end{equation*}

    14.

    Consider the function \(f(x,y) = x^2 + xy + y^2\text{.}\)
    1. Find the directions in which \(f(x,y)\) increases and decreases most rapidly at \(P_0(-1,1)\text{.}\)
      🔗
      🔗
    2. Find the derivatives of \(f(x,y)\) in these directions at \(P_0(-1,1)\text{.}\)
      🔗
      🔗
    🔗
    Solution.
    1. The gradient is
      \begin{align*} \nabla f \amp = (2x + y)\,\hat{\imath} + (x + 2y)\,\hat{\jmath},\\ \left(\nabla f\right)_{(-1,1)} \amp = \langle -1, 1\rangle, \qquad \left\|\left(\nabla f\right)_{(-1,1)}\right\| = \sqrt2. \end{align*}
      The function increases most rapidly in the direction of the gradient,
      \begin{equation*} \hat u_1 = \frac{\left(\nabla f\right)_{(-1,1)}} {\left\|\left(\nabla f\right)_{(-1,1)}\right\|} = \left\langle -\frac{1}{\sqrt2}, \frac{1}{\sqrt2}\right\rangle, \end{equation*}
      and decreases most rapidly in the opposite direction,
      \begin{equation*} \hat u_2 = -\frac{\left(\nabla f\right)_{(-1,1)}} {\left\|\left(\nabla f\right)_{(-1,1)}\right\|} = \left\langle \frac{1}{\sqrt2}, -\frac{1}{\sqrt2}\right\rangle. \end{equation*}
      🔗
      🔗
    2. The directional derivatives are
      \begin{align*} \left(D_{\hat u_1} f\right)_{P_0} \amp = \left(\nabla f\right)_{(-1,1)} \cdot \hat u_1 = \frac{1}{\sqrt2} + \frac{1}{\sqrt2} = \sqrt2 = \left\|\left(\nabla f\right)_{(-1,1)}\right\|,\\ \left(D_{\hat u_2} f\right)_{P_0} \amp = \left(\nabla f\right)_{(-1,1)} \cdot \hat u_2 = -\frac{1}{\sqrt2} - \frac{1}{\sqrt2} = -\sqrt2 = -\left\|\left(\nabla f\right)_{(-1,1)}\right\|. \end{align*}
      As expected, the largest possible rate of change is \(\|\nabla f\|\) and the smallest is \(-\|\nabla f\|\text{.}\)

      🔗

      🔗

      🔗

    🔗
    Solution.
    Let \(\rho(x,y) = 100 + 0.1xy + 0.1y^2\text{.}\) Then
    \begin{equation*} \nabla \rho = \langle 0.1y,\; 0.1x + 0.2y\rangle, \qquad \nabla \rho\big|_{(10,10)} = \langle 1,\; 1 + 2\rangle = \langle 1, 3\rangle. \end{equation*}

    \begin{equation*} s \approx \frac{6}{3} = 2 \text{ units}. \end{equation*}

    17. The Fall Line on a Ski Slope.

    A mountainside has elevation, in feet,
    \begin{equation*} h(x,y) = 3000 - 0.0004x^2 - 0.001y^2, \end{equation*}
    with \(x\) and \(y\) in feet. A skier stands at \(P_0(200,100)\text{.}\) Her gravitational potential energy is \(U = mgh\text{,}\) so the downhill force she feels is a positive multiple of \(-\nabla h\text{.}\)
    🔗

      🔗
      🔗
    2. A traverse is a route on which she neither climbs nor descends. Find the two unit vectors that accomplish this.
      🔗
      🔗
    3. She wants a gentler line of exactly \(12\%\) grade. Using \(D_{\hat{u}}h = \|\nabla h\|\cos\theta\text{,}\) find the angle \(\theta\) between her heading and the fall line.

    18.

    You measure the magnitude of a force \(F\) to be \(6\text{,}\) but there could be an error of at most \(\pm 0.3\text{.}\) You measure a mass \(M\) to be \(3\) with an error of at most \(\pm 0.1\text{.}\) You are trying to use these two to approximate the magnitude of the acceleration \(A\text{.}\) We have \(A = \dfrac{F}{M}\text{.}\) Use the principle of the differential to find an upper bound on the absolute value of the error when assuming \(A = 2\text{.}\)
    🔗
    Solution.
    Treat \(A\) as a function of the two measured quantities, \(A(F,M) = \dfrac{F}{M}\text{.}\) Its differential is
    \begin{equation*} dA = \frac{\partial A}{\partial F}\,dF + \frac{\partial A}{\partial M}\,dM = \frac{1}{M}\,dF - \frac{F}{M^2}\,dM. \end{equation*}
    At the measured values \(F = 6\) and \(M = 3\) (where indeed \(A = 2\)), the coefficients are \(\frac13\) and \(-\frac{6}{9} = -\frac23\text{.}\)
    🔗
    Taking absolute values and using the triangle inequality with the worst-case errors \(|dF| \le 0.3\) and \(|dM| \le 0.1\text{,}\)
    \begin{equation*} |dA| \le \frac{1}{3}|dF| + \frac{2}{3}|dM| \le \frac13(0.3) + \frac23(0.1) = 0.1 + \frac{1}{15} = \frac16. \end{equation*}
    So the error in the value \(A = 2\) is at most about \(\frac16 \approx 0.167\text{.}\)

    19.

    Let \(g(x,y) = \sin(xy)\text{,}\) and note that \(g\!\left(\pi, \tfrac13\right) = \tfrac{\sqrt3}{2}\text{.}\) Use an appropriate partial derivative to approximate \(g\!\left(\pi, \tfrac13 + \tfrac1{20}\right)\text{.}\)
    🔗
    Solution.
    Only \(y\) changes, by \(\Delta y = \tfrac1{20}\text{,}\) so we need \(g_y\text{.}\) Treating \(x\) as a constant and using the chain rule,
    \begin{equation*} g_y(x,y) = x\cos(xy) . \end{equation*}
    🔗
    At the point \(\left(\pi, \tfrac13\right)\) we have \(xy = \tfrac{\pi}{3}\) and \(\cos\!\left(\tfrac{\pi}{3}\right) = \tfrac12\text{,}\) so
    \begin{equation*} g_y\!\left(\pi, \tfrac13\right) = \pi \cdot \frac12 = \frac{\pi}{2} . \end{equation*}
    🔗
    Therefore
    \begin{align*} g\!\left(\pi, \tfrac13 + \tfrac1{20}\right) \amp \approx g\!\left(\pi, \tfrac13\right) + g_y\!\left(\pi, \tfrac13\right)\cdot \frac{1}{20}\\ \amp = \frac{\sqrt3}{2} + \frac{\pi}{2}\cdot\frac{1}{20}\\ \amp = \frac{\sqrt3}{2} + \frac{\pi}{40} \approx 0.944 . \end{align*}
    The exact value is \(\sin\!\left(\tfrac{23\pi}{60}\right) \approx 0.933\text{,}\) so again the approximation is quite good.

    20. True or False.

      If every directional derivative \(D_{\mathbf u}f(P_0)\) exists at a point \(P_0\text{,}\) then \(f\) must be continuous at \(P_0\text{.}\)
      🔗
      Justify your answer fully: give a proof if the statement is true, or a counterexample if it is false.
      🔗

    • True.

    • False, and the failure is dramatic. Let
      \begin{equation*} f(x,y) = \frac{x^2 y}{x^4 + y^2}\ \text{ for } (x,y)\ne(0,0), \qquad f(0,0) = 0 . \end{equation*}
      For a unit vector \(\mathbf u = \langle a,b\rangle\) with \(b \ne 0\text{,}\)
      \begin{equation*} D_{\mathbf u}f(0,0) = \lim_{t\to 0}\frac{f(ta,tb)}{t} = \lim_{t\to 0}\frac{a^2 b}{t^2a^4 + b^2} = \frac{a^2}{b}, \end{equation*}
      and \(D_{\mathbf u}f(0,0) = 0\) when \(b = 0\text{.}\) So every directional derivative exists. Yet along the parabola \(y = mx^2\text{,}\)
      \begin{equation*} f(x,mx^2) = \frac{m}{1+m^2}, \end{equation*}
      which depends on \(m\) — different parabolas approach different values, so \(\lim_{(x,y)\to(0,0)}f\) does not exist and \(f\) is not continuous at the origin. Existence of directional derivatives is a statement about behavior along straight lines only; continuity requires control along every approach.
