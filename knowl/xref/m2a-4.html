Worksheet Exercise 21.

A surveyor determines that the three points
\begin{equation*} A = (-1,2,16), \qquad B = (2,-2,17), \qquad C = (2,0,16) \end{equation*}
all lie on a flat surface \(W\text{.}\)
  1. Find the point of \(W\) that is closest to the point \((4,4,-3)\text{.}\)
    🔗
    🔗
  2. Find parametric equations for a line that passes through \((4,4,-3)\text{,}\) never crosses \(W\text{,}\) and satisfies \(x(t) = y(t)\text{.}\)
    🔗
    🔗
🔗
Solution.
Finding the plane. Two vectors lying in \(W\) are
\begin{equation*} \vec{AB} = \left\langle 3,\ -4,\ 1 \right\rangle , \qquad \vec{AC} = \left\langle 3,\ -2,\ 0 \right\rangle . \end{equation*}
A normal vector is their cross product:
\begin{align*} \vec n \amp = \vec{AB}\times\vec{AC} = \begin{vmatrix} \mathbf i \amp \mathbf j \amp \mathbf k \\ 3 \amp -4 \amp 1 \\ 3 \amp -2 \amp 0 \end{vmatrix}\\ \amp = \left\langle (-4)(0)-(1)(-2),\ (1)(3)-(3)(0),\ (3)(-2)-(-4)(3) \right\rangle\\ \amp = \left\langle 2,\ 3,\ 6 \right\rangle . \end{align*}
Note \(\|\vec n\| = \sqrt{4+9+36} = 7\text{,}\) which will be convenient. Using the point \(A\text{,}\) the plane is
\begin{align*} 2(x+1) + 3(y-2) + 6(z-16) \amp = 0\\ 2x + 3y + 6z \amp = 100 . \end{align*}
(Check: \(B\) gives \(4-6+102 = 100\) and \(C\) gives \(4+0+96 = 100\text{.}\))
🔗
(a) The closest point of a plane to a given point \(Q = (4,4,-3)\) is the foot of the perpendicular from \(Q\text{,}\) which we reach by moving from \(Q\) in the direction of the normal. So consider
\begin{equation*} \vec r(t) = Q + t\,\vec n = (4+2t,\ 4+3t,\ -3+6t) \end{equation*}
and find the value of \(t\) for which this point lies on \(W\text{:}\)
\begin{align*} 2(4+2t) + 3(4+3t) + 6(-3+6t) \amp = 100\\ 8 + 4t + 12 + 9t - 18 + 36t \amp = 100\\ 2 + 49t \amp = 100\\ t \amp = 2 . \end{align*}
Therefore the closest point is
\begin{equation*} \vec r(2) = (4+4,\ 4+6,\ -3+12) = (8,\ 10,\ 9) . \end{equation*}
(Check: \(16 + 30 + 54 = 100\text{.}\)) Incidentally, the distance from \(Q\) to \(W\) is \(|t|\,\|\vec n\| = 2\cdot 7 = 14\text{.}\) See Figure 5.9.41.
🔗
(b) A line never crosses the plane \(W\) exactly when it is parallel to \(W\) and does not lie in it. Since \(Q = (4,4,-3)\) is not on \(W\) (we saw \(2(4)+3(4)+6(-3) = 2 \ne 100\)), we only need the direction vector \(\vec d = \left\langle a, b, c\right\rangle\) to be perpendicular to the normal:
\begin{equation*} \vec d \cdot \vec n = 2a + 3b + 6c = 0 . \end{equation*}
🔗
The extra requirement \(x(t) = y(t)\) forces the two lines \(x = 4 + at\) and \(y = 4 + bt\) to agree for all \(t\text{,}\) which happens exactly when \(a = b\text{.}\) Substituting \(b = a\text{,}\)
\begin{equation*} 2a + 3a + 6c = 0 \quad\Longrightarrow\quad 5a = -6c . \end{equation*}
Choosing \(a = 6\) and \(c = -5\) gives \(\vec d = \left\langle 6,\ 6,\ -5 \right\rangle\text{,}\) and the line is
\begin{equation*} x = 4 + 6t, \qquad y = 4 + 6t, \qquad z = -3 - 5t . \end{equation*}
Indeed \(x(t) = y(t)\) for every \(t\text{,}\) and \(\vec d\cdot\vec n = 12+18-30 = 0\text{,}\) so the line is parallel to \(W\) and, starting from a point off \(W\text{,}\) never reaches it.
