Definition 4.5.8. Gradient Vector.

The gradient vector of the function \(f(x,y)\) at \(P_0(x_0,y_0)\) is the vector
\begin{equation} \left(\nabla f\right)_{P_0} = \left(\frac{\partial f}{\partial x}\right)_{P_0}\hat{\imath} + \left(\frac{\partial f}{\partial y}\right)_{P_0}\hat{\jmath}.\tag{4.5.4} \end{equation}
🔗
The gradient vector and the directional derivative of \(f(x,y)\) at \(P_0(x_0,y_0)\) in the direction \(\hat{u} = u_1\hat{\imath} + u_2\hat{\jmath}\) are related via the following dot product:
\begin{equation} \left(\frac{df}{ds}\right)_{\hat{u},\,P_0} = \left(\nabla f\right)_{P_0}\cdot\hat{u}.\tag{4.5.5} \end{equation}
