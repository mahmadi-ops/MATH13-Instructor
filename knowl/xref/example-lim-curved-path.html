Example 4.2.13. Straight Lines Are Not Enough.

Evaluate the following limit, or show that it does not exist.
\begin{equation*} \lim_{(x,y)\to(1,2)} \frac{(x-1)^2(y-2)^3}{(x-1)^4+(y-2)^6}. \end{equation*}
🔗
Solution.
Direct substitution gives \(\frac{0}{0}\text{,}\) and this time nothing cancels. To keep the algebra short, write \(u = x - 1\) and \(v = y - 2\text{.}\) Then \((x,y)\to(1,2)\) exactly when \((u,v)\to(0,0)\text{,}\) and the function becomes
\begin{equation*} f(x,y) = \frac{u^2v^3}{u^4+v^6}. \end{equation*}
🔗
Let us first approach \((1,2)\) along straight lines. Along the vertical line \(x = 1\) we have \(u = 0\text{,}\) so \(f(x,y) = 0\text{.}\) Every other line through \((1,2)\) is \(y - 2 = m(x-1)\text{,}\) that is, \(v = mu\) with \(m \in \R\text{,}\) and along it (with \(u \neq 0\))
\begin{equation*} f(x,y) = \frac{u^2\,m^3u^3}{u^4+m^6u^6} = \frac{m^3u}{1+m^6u^2}, \end{equation*}
which tends to \(0\) as \(u \to 0\text{.}\) So \(f(x,y) \to 0\) as \((x,y) \to (1,2)\) along every straight line through \((1,2)\text{.}\)
🔗
Straight lines are not the only paths, however. The two terms of the denominator are equal when \(u^4 = v^6\text{,}\) that is, when \(u^2 = v^3\text{,}\) so consider the curve \((x-1)^2 = (y-2)^3\text{.}\) It can be traced as
\begin{equation*} x = 1 + t^3, \qquad y = 2 + t^2, \qquad t \to 0, \end{equation*}
for which \(u = t^3\) and \(v = t^2\text{.}\) Along it, for \(t \neq 0\text{,}\)
\begin{equation*} f(x,y) = \frac{t^6\cdot t^6}{t^{12}+t^{12}} = \frac{1}{2}, \end{equation*}
and hence \(f(x,y) \to \frac12\) as \((x,y) \to (1,2)\) along this curve. The function approaches \(0\) along every straight line but \(\frac12\) along this curve, so the limit does not exist.
