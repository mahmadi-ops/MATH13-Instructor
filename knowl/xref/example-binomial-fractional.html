Example 2.4.5. The power is not an integer.

Use binomial series to write the function \(f(x) = (x+1)^{\frac12}\) as a series. Compute the five non-zero terms.
🔗
Solution.
We apply the binomial series (2.4.6) with \(m = \frac12\text{:}\)
\begin{equation*} (1+x)^{\frac12} = 1 + \sum_{k=1}^{\infty} \binom{\frac12}{k} x^k \end{equation*}
🔗
The coefficients are
\begin{align*} \binom{\frac12}{1} \amp = \frac12,\\ \binom{\frac12}{2} \amp = \frac{\frac12\left(\frac12 - 1\right)}{2} = \frac{\frac12\left(-\frac12\right)}{2},\\ \binom{\frac12}{3} \amp = \frac{\frac12\left(\frac12 - 1\right)\left(\frac12 - 2\right)}{3!} = \frac{\frac12\left(-\frac12\right)\left(-\frac32\right)}{3!},\\ \binom{\frac12}{4} \amp = \frac{\frac12\left(\frac12 - 1\right)\left(\frac12 - 2\right) \left(\frac12 - 3\right)}{4!} = \frac{\frac12\left(-\frac12\right)\left(-\frac32\right) \left(-\frac52\right)}{4!}. \end{align*}
🔗
Hence the five non-zero terms are
\begin{equation*} (1+x)^{\frac12} = 1 + \sum_{k=1}^{\infty} \binom{\frac12}{k} x^k = 1 + \frac12 x - \frac{x^2}{8} + \frac{x^3}{16} - \frac{5x^4}{128} + \cdots \end{equation*}
🔗
